# FolderLens 候选版本

这是尚未完成一期全部验收的 Windows x64 候选版本。它没有代码签名，可能出现 Windows 的未知发布者提示。验收状态见 `CAPABILITIES.json`，组件版本和第三方声明见 `SBOM.json` 与 `THIRD-PARTY-NOTICES.md`。

解压便携 ZIP 到本机可写文件夹后，运行 `app\FolderLens.App.exe`。请完整保留 app 下的文件和子目录。便携数据位置由 `portable.json` 指定为应用目录下的 `data`。不要直接在压缩包或网络共享中运行。

安装版本为当前用户安装，不需要管理员权限。默认安装到 `%LOCALAPPDATA%\Programs\FolderLens`；设置、索引和缓存位于 `%LOCALAPPDATA%\FolderLens`。升级保留旧版本文件和用户数据，卸载默认保留用户数据，可明确选择删除应用数据。不会修改素材目录。

选一个根目录即可查看其各级子目录的文件。筛选影响当前结果列表；图片可查看原图、缩放和切换，视频由本机播放器打开。Markdown 离线预览所需的固定 WebView2 已随包提供。本机没有默认媒体播放器时，需在应用中选择本机播放器。

本版本不自动联网更新，不捆绑 PotPlayer，不修改文件关联或开机启动项。查看期间不应改写源文件。若出现错误，请保留本版本的构建编号和错误提示以便复现；不要提交私人照片、全文或含个人路径的诊断材料。
