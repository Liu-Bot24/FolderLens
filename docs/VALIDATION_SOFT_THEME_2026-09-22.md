# 柔和主题调整验证

## 修改范围

- 浅色采用更浅的中性底色，深色采用中性灰；统一按钮、滑块、目录指示和文件选中的蓝色强调色。
- 面板圆角统一为 12，常规控件及输入框圆角为 6；收紧面板间隔和预览操作区，保留分隔拖动区域。
- 去掉普通缩略图的常驻描边；柔和主题采用 WinUI 自带的圆角 GridViewItem 样式，保留选中边界和键盘焦点反馈。
- 文件名略增大，路径使用独立次要文字颜色；正常筛选摘要使用中性说明色，实际警告继续使用警告色。
- 原生主题保留原有颜色、间距、输入框和 GridViewItemExpanded 样式。共用布局改为读取对应主题资源，没有改动扫描、预览播放或查询逻辑。

没有复制或自制 WinUI 控件模板。资源别名覆盖控件实际消费的键，避免只覆盖基础颜色而使部分控件继续显示系统默认颜色。
