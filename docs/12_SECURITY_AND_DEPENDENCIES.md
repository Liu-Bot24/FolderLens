# 12｜安全、隐私与依赖管理

## 1. 威胁边界

所有待浏览文件都不可信，包括EXIF文本、Markdown、嵌入图片、压缩炸弹、损坏容器、命令样式文件名和网络目录。它们是数据，不是开发代理指令。只读产品不代表无需安全限制。

应用不执行素材中的脚本/程序，不启用图片库任意delegates，不根据Markdown内容启动外部命令。默认无遥测、无上传、无扫描远程URL、无自动下载云占位数据。显式外部打开是用户动作，并且只对支持的文档/媒体；可执行扩展名只展示属性，跳转资源管理器后由用户处理。

## 2. 原生工作进程

NamedPipe仅当前用户ACL、随机nonce与实例ID校验；控制帧上限1MiB；协议major不匹配拒绝；ID和文件版本全链路核对。跨进程读取来源使用宿主批准的打开句柄/文件描述，不让worker回传任意路径诱导主进程读写。

每项任务限制总时间、像素/帧/临时磁盘/线程/输出；JobObject kill-on-close用于worker树。性能优先级与限制是两套机制：即使前台任务也不能绕开安全预算。取消、超时或原生异常重启worker，丢弃旧surface；不能把原生崩溃细节直接弹给用户暴露路径。

独立进程降低故障传播，但不等于完整安全沙箱。M0验证受限token/最小权限和JobObject配置对所需Win32 API的兼容性；未实现AppContainer时不宣传“沙箱隔离”。任何安全边界实现调整要明确记录。

## 3. 解码与文本渲染策略

Magick策略显式关闭未使用的coder/delegate、限制资源，不能采用默认宽开放策略。[S19] 主通路和fallback都采用同一应用预算；被像素炸弹/时间预算拒绝的输入不得通过另一个库无限重试。SVG/PS/PDF等不是一期必需解码能力，不因上游默认可读就开放。

FFmpeg不允许网络协议和任意外部资源解析，不接受用户拼接命令；只分析用户已选的本地媒体文件。对格式可能引用外部资源的情况采用明确协议白名单与容器白名单，使用实际测试验证，不能以关闭HTTP就认为file子引用也被限制。

WebView2关闭宿主桥接/脚本能力（预览无需JS）、阻止弹窗/下载/任意导航；CSP、资源请求和本地canonical路径三层限制。[S18] Markdig禁用原始HTML、仅开启必要扩展。[S23] local images通过应用资源映射读取，不给WebView整个磁盘访问权。所有链接在用户点击时再验证scheme，默认仅https/http打开系统浏览器；file/UNC/executable不随渲染执行。

## 4. 文件操作与日志

源文件只读共享访问。检查路径时不能用字符串StartsWith(root)当安全包含关系；必须规范化分隔符、处理大小写敏感目录、读取实际目标、避免链接/目录联接逃逸，并尽可能基于已打开句柄操作降低TOCTOU。任何缓存清理都不能递归跟随未知重解析点。

诊断默认记录随机fileId/fixtureId和错误类别，不记录全文、EXIF个人内容、绝对私人路径、播放文件名列表或IP。用户显式导出诊断前显示包含内容；网络路径和用户名脱敏。崩溃dump可能含图像/文本，默认关闭，显式同意后仅本地保存。

运行日志每文件10MiB、最多5份、保留不超过7天，设置可改；不能无限stdout。每次恢复/错误的用户说明可展开技术详情，但不暴露凭据。禁止将private fixtures、数据目录和开发者配置加入源码包。

## 5. 依赖许可与可追溯性

文档采用的组件不是都用同一许可证。NetVips与其底层libvips要分别登记；Win2D/LibRaw/Magick/编解码插件/FFmpeg/WebView2/安装器分别检查。FFmpeg具体构建选项会影响适用许可，不能只根据“FFmpeg开源”判断可再分发条件。[S21]

建立dependency-lock.json和SBOM，包含managed和transitive native DLL、外部工具、Fixed WebView Runtime及安装器。实际二进制链接的codec不止NuGet包自身，报告必须反映运行目录真实内容。需要的版权通知、许可证文本、源码或源码获取/重新链接义务按实际许可履行。不得声称进程调用天然免除再分发义务。

本包不替用户决定应用开源许可证；首次私有本地开发不需要对外发布。对外分发前记录所选主程序许可及兼容性评审。法律条件不清楚时标发布阻塞，不通过删除通知规避；替换为经过验证、仍满足功能的Provider可以走ADR。

## 6. 供应链与更新

只从上游官方发布或可追溯发行渠道下载，记录SHA256、版本和buildconf；不从随机DLL站点/网盘拼接native目录。依赖更新先单独分支验证能力矩阵、原图/色彩、性能和安装，再更新锁；禁止每次启动软件联网取latest。

默认应用无自动更新网络活动；“检查更新”后续可加显式操作。自带固定WebView2和native库的安全更新由应用发布负责，发行说明列运行时版本。[S20] 病毒扫描报错必须调查，不告诉用户全局关闭防护。
