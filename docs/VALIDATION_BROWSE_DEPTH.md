# 浏览层级与预览操作

- 路径栏旁的“查看层级”默认所有层级，提供 1–5 层及自定义整数层数。当前文件夹算第 1 层；改变层级不重新扫描。
- 文件搜索只匹配文件名，已移除搜索路径的勾选。旧保存视图也不能重新开启路径匹配。
- 格式文字和格式弹层沿左边缘对齐。窗口预览、全屏预览移至左侧预览区域；100% 按钮改为内容宽度，避免文字裁切。

## 旧视图恢复修正

Pro 发现恢复入口先比较旧 `recursive=false`，随后才转换为 1 层，导致同根误判需要重扫。现改为恢复入口先生成统一的浏览条件，再用于策略比较、控件应用和待恢复记录；底层扫描策略比较保持原义。新增单元验证相同排除不重扫、不同扫描排除仍需重扫、旧值映射 1 层、新层级与全部保留。相关 12 项测试通过，Release 构建 0 错误。原生用例已调用完整 `RestoreSavedView` 并检查 rootChangeVersion、epoch 和扫描 Task 不变，但该原生用例仅编译、未执行。
