# 一期范围收束后的实施与验证

本批在 `25efa9f` 审计返回前完成独立播放/音频工作，返回后先修复八项意见，再完成多页文件路由与文本、资源处理。没有重开安装版、替换安装文件或扫描用户归档。

| 项目 | 结果与证据边界 |
|---|---|
| 视频批量播放 | 保持固定结果顺序；10,000 个允许，10,001 个拒绝整个请求；不分段、不产生部分最终列表。单元测试通过；未以此宣称真实播放器内部队列验收。 |
| 音频失败恢复 | 原生 MediaFailed 后释放旧播放对象；生成的静音 WAV 可重试播放，旧回调不覆盖新选择；使用系统默认设备。实际拔耳机未测试。 |
| 多页扫描文件 | 双页 TIFF 经后台检测或首次冷预览均成为普通文件；图片筛选排除，全部文件保留。单页、动画、RAW 反例和带备份旧索引迁移测试通过。 |
| 显示器 | 两块现有屏幕均为 144 DPI / 150%。100% 像素比例、适应屏幕边界与目录/选择/结果源保留通过；不同 DPI 的物理迁移未测试。 |
| 内存压力 | 复用现有进程资源监控，取消预取并释放其图片和细节缓存；当前显示位图与选择保留。没有通过耗尽整机内存制造压力。 |
| 文本索引缓存 | 每目录最多 8 个、单个 64 MiB；清理旧非活动缓存，保护活动索引、未知文件与源文件。超限索引失败时原文仍可读取。 |
| Markdown 资源 | 路径核验移到现有隔离文件访问进程，带超时/取消；有效本地图片在实际 WebView2 中显示，越界路径拒绝。 |
| 综合浏览回归 | 200 帧无缩略图空白或容器替换，12 个可见行在两处插入后保留；目录历史、递归、分组重排、缓存写入失败回退和单页图片设备恢复通过。 |

最终 Release 构建通过；全套单元测试 **244 通过、0 失败、0 跳过**。原生阅读验证使用正常子进程权限，因为受限沙箱会阻止 WebView2 初始化；未更改产品阅读逻辑来绕过该环境限制。

旧综合用例仍要求 TIFF 第二页导航，因此按取消后的范围失败；已替换为普通文件路由，并保留单页图片设备恢复、旋转与倍率检查。显示器用例的 WinRT 枚举投影失败改用集合索引访问；这些验证代码修正不作为产品缺陷宣称。

仍未通过本批验证的项目：用户实际归档刷新、混合 DPI、耳机拔插、外部播放器实际列表顺序、网络位置、干净部署及完整规模/长时间性能。未据此宣布一期整体完成或新一轮审计通过。
