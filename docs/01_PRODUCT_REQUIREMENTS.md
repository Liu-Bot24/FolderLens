# 01｜产品需求与行为合同

## 1. 打开与范围

启动先恢复窗口和上次已建立索引的目录；目录不在线时展示离线状态和缓存记录，不弹出阻塞登录窗口。第一次启动显示“打开文件夹”，不自动扫描整台电脑。

根目录选择器、拖入目录、命令行 --root 三个入口等价。拖入单个支持文件或 --open：打开其父目录的非递归文件会话，选中该文件；不无意扫描整个磁盘。用户打开根目录则递归默认开启。拖入多个文件一期提示仅支持单目录/单文件入口，不自行移动素材。

索引所有枚举到的普通文件，为容量统计提供完整逻辑范围；昂贵媒体分析仅按支持类型和需求调度。默认浏览类别为“图片”，RAW 包含；可切换图片/视频/音频/文本/全部。默认不隐藏零字节文件，只对其显示不能预览。

隐藏文件/目录默认收录并计入容量，但列表默认隐藏；系统文件目录默认不递归，单独列出排除范围。重解析目录默认不跟随。用户明确选择一个联接/符号链接作为根时先解析目标并显示真正扫描位置；子目录联接仍跳过。云占位目录枚举或文件读取可能下载内容时必须尊重 docs/04 的本地优先策略。

## 2. 筛选语义

同一组内选项 OR，组与组 AND。空选项集合表示该组不限；“不选任何格式”的 UI 必须另有明确空结果操作，不能让用户误以为清空勾选仍有限制。

| 属性 | 精确定义 |
|---|---|
| 类型 | image/video/audio/text/markdown/other；markdown 在“文本”标签中合并展示，但可独立选择 |
| 格式 | 探测后的容器/图片格式；扩展名另存。不假定 .jpg 一定是 JPEG。未探测用候选分类并显示待确认 |
| RAW | Any/Only/Exclude 三态，与格式条件 AND；Only只匹配RAW图片，Exclude保留非图片但排除确认RAW；冲突时清晰展示零结果及冲突说明 |
| 动静态 | Any/Animated/Static。Animated/Static仅适用于图片，非图片为NoMatch；Any不限。多页 TIFF 不属于 Animated，静态指非时间动画；动画判断未知不是 Static |
| 尺寸 | 展示方向生效后的 width/height；保留 encodedWidth/encodedHeight 供属性面板查看 |
| 分辨率 | 以总像素 width×height 为“像素数/MP”；“4K”不作为含糊自由选项，预设转换为明确宽高条件 |
| 长短边 | max(width,height)、min(width,height)，方向不影响其值 |
| 比例 | width/height；横向 >1.02，正方形 0.98–1.02，竖向 <0.98；比例范围可精确输入 |
| 体积 | logicalBytes；以字节比较。UI 输入默认 MiB/GiB，可选 MB/GB，必须标单位与换算 |
| 分配大小 | allocatedBytes，可能未知/不支持；不是删除可释放量 |
| 日期 | 创建/修改/拍摄时间字段独立；拍摄时间无时区时保留本地墙钟及 timezoneUnknown 标识，不强行当 UTC |
| 时长 | 毫秒，比较使用 64 位值；无时长不是 0 |
| 名称/路径 | 文字包含；多词 AND；支持双引号短语。默认名称，用户可开启相对路径；不做全文内容跨文件索引 |

所有数值区间含上下界；日期 UI 使用本地自然日，转换为开始含/下一天开始不含；缺失拍摄时间不回退成修改时间。正负/溢出/NaN/上下界倒置直接显示校验错误，不发送查询。

图片几何条件默认仅匹配图片；视频几何条件需当前类别含 video，按显示尺寸/DAR/旋转处理。音频不会因为尺寸未知而被算作“待分析图片”。类型适用性先判定，再判元数据未知。

## 3. Unknown、Failed 与可见结果

元数据状态按字段组独立：identity/imageGeometry/animation/imageColor/captureTime/media/allocation。至少区分 notRequested/pending/ready/failed/unsupported/deferredOffline。不能只有一个 HasMetadata 布尔值。

查询返回 Match、NoMatch、Pending、Unresolvable 四种解释；任何已知条件 false 时是 NoMatch；条件适用但有未知值且其余不 false 时是 Pending；永久失败/不支持导致不能判定则 Unresolvable。

默认主列表只展示确定 Match，并显示“已符合 X；待判断 Y；无法判断 Z；扫描未完成”。用户可切换“查看待判断”，该列表有明显状态标记，不计入符合计数。Y/Z 未分析完时，不声称结果完整。按尺寸筛选只优先补齐尺寸，不因此生成整个目录缩略图。

无元数据条件的全图片列表可先展示按扩展名推测的 imageCandidate；随后类型确认变更产生“结果已更新”提示，而非静默调整活动浏览序列。伪装扩展名测试必须覆盖。

## 4. 排序与稳定性

排序项：自然文件名、相对路径、逻辑大小、分配大小、修改/创建/拍摄时间、宽高、长边、像素数、比例、时长。默认为自然文件名升序，次级相对路径升序，再 fileEntryId。所有排序都有唯一最终键，NULL 不论升降均最后。

自然排序不使用本机区域设置随意变动的比较结果；实现项目固定排序算法/排序键版本，要求 file2 < file10，超长数字不溢出，大小写折叠规则稳定。相同规范键再以原始 UTF-16 ordinal 和文件 ID 拆平局。中文按固定 ordinal，而非未说明的拼音。

排序改变产生新的 queryGeneration。滑动、双击、选中和左右切换都基于当前结果会话。单图查看启动后固化文件顺序；元数据或目录变化只显示更新提示，用户刷新才替换。已删除项跳过并提示，但不让导航无限循环。

刚开始扫描只提供“已发现内容”的阶段结果；不能把目前最大项宣传为整个目录最大。支持任意位置滚动的完整快照建立后，按 ordinal 读取，不使用巨量 OFFSET。

## 5. 目录排除

视图排除（HideInView）仅隐藏当前范围；扫描排除（SkipScan）不递归、不探测，也不计入“已扫描范围”容量。两者在设置中分组，文案不可混用。

一期排除由目录树选择真实目录，不做任意通配符引擎。规则保存在根目录设置中，匹配目录身份和路径段边界，不使用简单 StartsWith 误排“素材2”。目录在根内重命名且身份可追踪时规则跟随；身份不可靠时保留旧规则并提示失效，不扩大匹配范围。

新增 SkipScan 立即停止其子树排队工作；既有索引标记 excluded，不视为已删除。移除 SkipScan 后仅补扫该子树。HideInView 不取消与“整个扫描范围容量”相关的廉价基础信息收集。

## 6. 结果操作与状态恢复

右键/按钮支持复制完整路径、相对路径、复制文件引用、在资源管理器定位、用指定程序打开、查看属性。可执行文件或脚本的 other 类型只显示属性和定位，不由本应用执行；外部打开只用于文档/媒体，预览永远不执行。

多选可用于复制路径/文件引用和视频播放列表；不实现批量删除/移动。Ctrl+A 保存选择谓词或范围，不在 UI 为百万项建立百万对象。超过 10,000 项的剪贴板文件引用拒绝并引导缩小选择；路径文本可分块生成到受控上限，不能卡住 UI。

保存预设包含 filter/sort/view/pathOverlay/previewLayout，不包含绝对素材副本。保存命名不能覆盖同名而不说明。根目录独立保存排除规则、最后选中 fileId、滚动锚点和布局。恢复时找不到旧文件则选择最接近的有效位置，不黑屏。

## 7. 错误和进度

根目录状态至少有 empty/scanning/ready/partial/offline/accessDenied/cancelled；文件预览状态至少有 none/queued/previewLoading/previewReady/fullLoading/fullReady/error/unsupported/offline。

根目录不存在、无权限、离线分别说明；单文件损坏不阻断后续文件；取消扫描保留已发现记录，但必须标“扫描未完成”。进度总量未知时不生成假百分比，只显示已发现/已分析/当前任务和可取消状态。

扫描错误提供按原因汇总和定位；默认日志路径匿名化。恢复失败允许重建索引，但重建前保存用户预设，不能自动清空全部数据掩盖错误。
