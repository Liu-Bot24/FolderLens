- 打开根时先取走旧快照句柄，释放完成后复查打开请求代次和关闭状态；过期请求不能继续创建扫描或发布查询。此 WinUI 交错仅源码复核与编译，未运行原生屏障测试。
- 临时扫描队列的增删和分支移动用同一事务内的触发器维护 pending 数；部分索引仅包含 pending>0 的可运行分支，耗尽分支保留轮次历史，重新入队不会重置公平次序。
- 移动目录同步更新队列路径、深度、分支；新分支继承原轮次，未移动队列不受影响。测试覆盖生产移动 SQL 的跨分支变更、重复入队、删除、再次入队和多扫描隔离；5000 个耗尽分支不改变选择，EXPLAIN 确认可运行部分索引被使用。未据此宣称真实耗时改善比例。
- 最终全量 366 项单元测试通过；WinUI Release 编译 0 错误、7 项 NU1900。日志 scan-audit-full.log、scan-audit-build.log；原生窗口及真实扫描移动反例仍未执行。
