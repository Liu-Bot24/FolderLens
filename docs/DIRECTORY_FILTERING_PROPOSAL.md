# 文件夹筛选方案（待实施）

## 建议的入口

在“筛选”中增加“文件夹”，分组标题右键提供“隐藏此文件夹及子文件夹”。工具栏显示已隐藏的文件夹数，可以查看、暂停规则或恢复全部。关闭文件夹分组后，规则仍然生效。

当前已有按具体相对路径“只在视图隐藏”和“完全不扫描”的排除能力。建议先完善视图筛选的交互与规则，默认保留索引，切换规则不重新扫描。明确选择“不扫描”的目录继续沿用现有扫描排除设置，不混用这两种效果。

## 常用规则无需正则

提供两种基础选择：

- 指定文件夹：从目录树勾选具体路径，明确是否包含子文件夹。
- 文件夹名称：名称“等于”“包含”“以……开头”，可以应用到所有层级。

默认使用“名称等于”，按完整目录段匹配，不把文件名混入匹配。路径均相对于当前浏览根目录；大小写遵循所在目录的文件系统语义。

| 需求 | 规则 | 应显示 | 应隐藏 |
| --- | --- | --- | --- |
| 保留正式图片、视频，排除所有“仅预览” | 隐藏名称等于“仅预览”的文件夹及子文件夹 | 图片、视频、视频\\预览 | 图片\\仅预览、视频\\仅预览 |
| 连“预览”也不要 | 再加一条名称等于“预览” | 图片、视频 | 预览、仅预览及其后代 |
| 只排除一个联系人的图片预览 | 选择具体的“联系人\\图片\\仅预览” | 其他联系人的同名目录 | 所选目录及其后代 |

“预览”和“仅预览”是用户自己的目录名，程序不赋予它们特殊含义。

## 包含、排除与例外

第一步选择浏览范围；没有包含规则时，以当前根目录为范围。有包含规则时，取这些规则匹配范围的并集。然后应用排除规则。明确指定具体路径的“保留例外”最后生效，可以恢复被名称规则排除的特定目录。界面显示规则的作用顺序，不依靠隐藏的优先级。

应用前预览将显示／隐藏哪些目录、文件数量，以及每个目录命中的规则。统计未完成时明确显示“部分统计”。折叠只收起显示；隐藏才改变浏览结果和数量，二者保持独立。切换规则尽量保留当前可见文件及滚动位置。

## 正则与 AI

正则放在高级选项，明确选择匹配“完整相对目录路径”或“单个文件夹名称”，提供测试区、错误提示及执行时间限制。常用规则优先编译为目录筛选，不逐文件运行正则。

AI 作为可选的规则填写助手，后续独立实施。用户自行配置服务地址、模型和 API 密钥；默认只发送用户输入的需求，目录示例由用户明确选择后才发送，不上传照片、文件内容或整个目录树。优先输出可解释的结构化规则；仅在必要时生成正则。结果必须经过本地校验和匹配预览，由用户点击“应用”，不得直接执行模型生成的代码。

## 建议分期

先实现具体目录勾选、精确名称排除、规则预览和保存方案；再补包含规则、保留例外和高级正则；最后接入可选 AI 助手。大目录测试同时覆盖规则切换、分页、分组计数、可见位置和缩略图任务取消，避免重现刷新闪烁。
