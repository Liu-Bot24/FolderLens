# 文件夹筛选

在“筛选 → 更多条件与目录排除…”中打开“文件夹筛选”。分组标题右键也可以选择“隐藏此文件夹及子文件夹”或打开规则设置。关闭分组后规则仍然生效。

## 常用操作

1. 选择“排除”“仅查看”或“例外保留”。
2. 选择匹配“文件夹名称”或“相对路径”；指定具体目录时可点“选择文件夹…”。
3. 默认“完全相同”，也可用“包含”“开头是”或高级正则。
4. 确认是否包括子文件夹，点击“添加规则”。
5. 点“预览筛选结果”查看已扫描内容中保留/隐藏的文件数量及最多 20 个隐藏目录示例，最后“应用筛选”。

例如，排除名称完全相同于 `仅预览` 的文件夹，会隐藏 `图片\仅预览`、`视频\仅预览` 及其后代；`视频\预览`、`图片\仅预览副本` 保留。程序不赋予这些名字特殊含义。

路径相对于当前浏览根目录。普通名称规则匹配完整目录段，不匹配文件名；所有规则不区分大小写。需要区分相似目录名时使用“完全相同”，避免“包含”扩大范围。

## 包含、排除和例外

没有“仅查看”规则时，默认查看当前范围全部文件夹。有多条“仅查看”规则时取并集；随后应用排除；“例外保留”优先于前两者。例如先排除名称 `预览`，再保留具体相对路径 `某联系人\视频\预览`。

规则旁的勾选框用于启用/停用；删除选中规则可永久移除该条筛选。规则仅影响当前视图，不修改文件、不丢弃索引，切换不需要重新扫描。预览只计算文件夹规则，其他格式、大小和日期条件仍在应用筛选时共同生效；扫描未结束时预览只覆盖已扫描内容。

“收藏 → 保存当前视图”会连同目录、类型、排序和文件夹规则一起保存；恢复收藏即可重复使用。

## 正则与不扫描设置

正则可针对单个文件夹名称或相对目录路径。名称例子 `^(仅预览|缓存)$`。相对路径中的反斜杠需要按正则语法转义；常用场景优先使用完全相同的名称或路径。正则采用非回溯引擎，支持普通分组、选择和重复，不支持环视及回溯引用；无效或不支持的表达式会直接提示，不会静默忽略。最多 64 条规则，每条最多 512 个字符，并设置匹配时间限制。匹配按目录计算，不对每个文件重复运行正则。

“不扫描的文件夹（高级）”与视图规则分开。这些目录不进入索引，修改后需要重新扫描；“例外保留”无法恢复没有扫描的数据。只是不想看到某些目录时，使用上面的文件夹筛选。
