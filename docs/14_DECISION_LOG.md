# 14｜决策记录与修改程序

## 已冻结ADR

| ADR | 决定 | 原因/禁止替代 |
|---|---|---|
| ADR-001 | Windows原生C#/.NET10/WinUI3 | Windows唯一平台；不为跨平台换Electron/Tauri |
| ADR-002 | 复用解码组件而非Fork完整看图软件 | 独特价值是递归结果集/筛选/容量；不自研codec |
| ADR-003 | 源目录为事实来源、只读、无导入副本 | 不改用户目录结构，缓存仅派生数据 |
| ADR-004 | 视频外部播放、音频单项原生试听 | 一期不实现专业视频播放器；视频结果序列仍完整传递 |
| ADR-005 | 巨大文本原文分页属于一期 | 不用整文件文本框；巨大MD不承诺完整富文本 |
| ADR-006 | SQLite本地+独立session数据库 | 不放SMB；固定浏览序列与任意位置取页 |
| ADR-007 | 进程隔离重型native调用 | 可超时/终止和故障恢复；不等同完整沙箱 |
| ADR-008 | 三层图像质量、RAW真实开发 | 不把缓存预览放大冒充清晰原图 |
| ADR-009 | SDR正确优先、HDR后续 | 保存精度与正确显示是不同能力，不做含糊宣传 |
| ADR-010 | 二期才写文件/转换 | 一期界面不放看似可用的导出/移动/删除按钮 |
| ADR-011 | 自包含目录式发布、每用户安装 | 用户不安装开发环境；不追求单文件假便携 |
| ADR-012 | 当前会话不随索引后台变化重新排序 | 避免切图跳变，显式刷新纳入新结果 |

## 允许代理独立处理的实现适配

修复SDK模板属性、替换等价且安全的native绑定、修改有证据的线程/缓存起始值、为APNG等选择通过实际测试的Provider、调整内部表/索引并迁移、改进大文本布局组件、更新安全补丁依赖。前提：不减范围、不降低原图/安全语义、不降低性能硬门禁，并留下反例、候选对比、选择依据和全量回归。

不能以“实现困难”为由把真实RAW改外部打开，把大文本改为超阈值不支持，把百万分页改全量内存，把Unknown写0，把所有目录体积算成当前可见图片之和，或在M0失败后偷偷换Web UI。

## 需要真实权限/产品决策的事项

主程序对外开源许可、付费证书/安装工具采购、系统级软件安装、上传私人素材、公开发布到用户账号、修改用户原文件、移除任何一期MUST。这些不是“普通实现细节”；环境缺权限就记录BLOCKED，不伪造确认。其他不依赖工作继续。

## ADR新增模板

编号/日期/构建；触发证据与最小复现；受影响需求/契约；至少两个可行实现的成本与风险；选定实现；保证不变的产品行为；需要的迁移；反例回归与性能复测；旧决定是否被替代。禁止只写“为了简化”或只改配置而不说明影响。
