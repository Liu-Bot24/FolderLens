# 一期范围与收尾顺序（2026-09-13）

本次范围调整优先于旧计划中的冲突条目；已具备的功能不因范围收束而无故删除。

- 文本阅读以大文件打开、滚动、查找保持响应和内存受控为重点。跨页任意文段选择不作为一期必做增强。
- 容量统计要求计算正确、范围明确、不阻塞浏览。增量或缓存是按测量选择的实现方式，不以持久聚合架构本身作为交付目标。
- 多页扫描图按普通文件浏览、显示信息并外部打开，不作为图片逐页查看的支持目标；静态单页图片与时间动画仍按各自类型处理。
- 视频调用系统关联或用户指定播放器，不研究播放器内部实现。批量播放保持当前结果顺序，一次最多 10,000 个视频；超限整个请求拒绝，不截断，也不提供下一段。
- 音频使用 Windows 系统播放设施。设备断开、切换及播放失败不能使浏览卡死，失败后应可重试。
- 多屏 DPI 是必要适配。高对比和系统文字缩放采用系统控件与资源做基础兼容，不扩展为深度专项。
- 网络位置、云占位和离线真实环境测试暂缓，由用户后续集中测试。
- 资源控制以成熟的虚拟化、有限并发、缓存上限和过时任务取消为基础；低配压力下保持可操作，不追求没有用户收益的架构复杂度。
- AI 规则助手留到下一期；跨文件全文索引、OCR 等扩展另行评估。

正在审计的固定版本为 `25efa9f`。审计期间优先完成音频/播放器、DPI 等独立模块，不同时改写首批结果、缩略图请求归属及分组通知；完整反馈返回后优先核实并修复明确缺陷。
