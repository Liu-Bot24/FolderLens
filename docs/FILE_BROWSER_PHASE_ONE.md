# 文件浏览器一期调整

## 定位与当前能力

FolderLens 将文件夹穿透作为核心：选定母文件夹，在一个窗口汇总浏览其所有子文件夹中的文件。图片、视频浏览继续增强，普通文档也必须能快速找到、辨认来源并打开。

已经具备网格和详细信息两种视图。此次文档类、音频和全部文件默认采用详细信息，图片和视频默认采用网格；用户手动切换后，同一运行期间记住该分类的选择。扫描过程中不依据文件数量自动切换布局，以免打断浏览。会话保存继续记录当前视图模式。

详细信息显示名称、相对路径、格式、大小、修改时间；图片额外显示尺寸，视频显示尺寸和时长，音频显示时长。占用空间默认隐藏。右键列标题可以选择显示列或恢复默认列，列宽及各分类的列选择会保存。文档、文本及未知类型在网格中使用文件图标和扩展名标记，支持的媒体封面加载后显示实际封面。

## 分类依据

对本地导出聊天归档进行只读扩展名统计，覆盖约 154.6 万个文件和 2.31 万个文件夹。除了大量图片，还有约 7.92 万个 Markdown、5.01 万个 MP3、2.24 万个 MP4、3,111 个 PDF、数千个表格/Word 文档和数百个演示文稿。

因此当前分类采用：图片、图片 + 视频、视频、音频、文本文件、PDF、Word 文档、Excel 表格、PPT 演示文稿、压缩文件、全部文件。CSV 同时适合文本阅读和表格查找，允许出现在两个分类中。未知类型仍出现在全部文件中，不因暂不支持预览而消失。

分类基于扩展名；内容格式识别另行显示，不能据此保证扩展名与内容一致。PDF/Office 暂以列表、属性和显式外部打开为范围，内部排版阅读不在此次交付内。

筛选中的“格式（扩展名）”自动列出当前分类与目录范围内的扩展名，可同时选择多种，
也可选择“无扩展名”或恢复“全部格式”。选项从目录索引读取，不必手填格式名称，
也不必等待图片解码。已有搜索或格式限制不会让其他扩展名选项消失。

左侧目录树保留桌面、下载、文档、图片、音乐、视频、用户文件夹，以及“此电脑”
中的磁盘入口。展开箭头逐层查看子文件夹，点击文件夹直接进入；“打开文件夹”
仍可用于快速选择位置。切换目录时保留导航入口与已展开的目录分支。

常用筛选采用双列布局，“应用筛选”“清除筛选”固定在面板底部。
通常无需滚动；窗口较小时仅条件区滚动，操作按钮保持可见。

## 已落地的文件夹筛选

在现有高级筛选中提供名称完全相同、包含、开头是、通配符、相对路径和高级正则。通配符 * 和 ? 不跨文件夹层级。支持仅查看、排除、例外保留，包括子文件夹开关、停用、预览和随收藏视图保存。分组标题右键可以隐藏该文件夹及子文件夹。

默认只改变显示；不清除索引、不重扫。完全不扫描仍是单独的高级设置，不能通过保留规则恢复尚未扫描的数据。AI 规则填写助手放到下一期。

## 本期查找功能与后续边界

| 功能 | 解决的问题 | 实施边界 |
|---|---|---|
| 类型与列设置 | 百万文件中辨认合同、表格、课件和媒体 | 记住分类视图及列宽，提供适用列；文件类型图标优先 |
| 日期筛选快捷项 | 找到某个时间段的交流材料 | 已提供今天、最近 7 天、最近 30 天和本月；使用文件属性或拍摄元数据，导出文件名日期不自动混用 |
| 文件夹来源筛选 | 只看某批群聊或联系人，排除封面/缓存目录 | 支持新增、编辑、启停、删除与匹配预览；不硬编码“仅预览”的业务含义 |
| 保存常用查询 | 反复查找“最近合同”“正式图片”“某批群聊的表格” | 使用收藏视图保存筛选、分组与布局；摘要显示生效条件 |
| 搜索范围可见 | 区分文件名、相对路径与文件正文 | 现有文件名/路径搜索和单个文本全文搜索清楚标注；跨文件正文搜索另列索引任务 |
| 返回上下文 | 看完内容后继续原来的查找 | 保留选中项、滚动位置、分组和筛选；选中、悬停、键盘焦点使用可辨认的视觉状态 |

跨文件正文索引、PDF/Office 正文抽取、OCR、相似图片检索、AI 搜索需要额外的资源预算、权限与召回质量验证；不能把“按扩展名筛选”当作已完成正文检索。这些项单独评估，AI 明确留到下一期。

一期整体按强制验收项及 [最新范围收束](PHASE_ONE_SCOPE_UPDATE.md) 判断。用户已取消或收束的要求不再沿用旧门禁。已实现某项界面或测试通过，不等于安装、真实大规模性能及所有格式验收全部完成。

## 文本阅读

TXT 默认换行，MD 支持排版和原文切换。阅读区提供返回文件列表、翻页、查找和字号按钮；返回保留原目录和选择。单页文档禁用翻页，Markdown 排版使用连续滚动。大文件按页读取，阅读工具提供全文搜索、编码选择和按行跳转。
