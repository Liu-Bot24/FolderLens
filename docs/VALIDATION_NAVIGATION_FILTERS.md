# 目录导航与格式选择验证

本批修复用户指出的手填格式、目录导航入口缺失和筛选面板过窄问题。

- 原格式框匹配内容识别后的 `format_id`，不能直接当作扩展名。
  现在从当前分类、目录范围及隐藏/目录规则的索引中读取扩展名，多选结果使用新增的
  可选 `fileExtensions` 条件，与分类条件取交集；旧 `formats` 保存筛选仍按原语义恢复，
  用户选择扩展名或清除时替换旧格式条件。空数组不限，空字符串代表无扩展名。
- 读取不等待解码，不访问源目录；使用有界数据库执行器、六秒取消和最多1024种选项。
  当前名称/格式/尺寸筛选不限制选项，避免筛选后失去其他格式。最多同时选择64种，
  超限明确提示；根和代次检查防止过时选项发布。
- 旧目录树在找不到目标时清空根节点，只重建当前路径祖先，并把少数常用目录附在后面。
  现在固定保留常用位置和此电脑下的注册盘符，沿最长已有祖先补齐目标路径，保持展开分支。
  下载目录取 Windows Known Folder 当前重定向路径；已知位置使用不验证存在的查询标志，
  创建导航入口时不读取磁盘卷标、不探测网络可用性。展开目录仍走原有隔离扫描工作进程。
- 筛选面板由280改为最大520 DIP的双列条件区，底部操作独立于滚动区。
  普通宽度实际高度469.3 DIP、零可滚动高度；360×320时仅条件区滚动，两个操作按钮仍可见。

`extensions-red.trx` 先证明扩展名条件未生效（期望1，实际3）。修复后单元用例覆盖
未解码元数据、大小写、多个扩展名、无扩展名、分类交集、目录/递归/隐藏范围以及其他根。
`navigation-roots-red` 证明缺失此电脑入口；修复后真实树节点展开和父/子/兄弟导航通过。

`navigation-filter-format-choices`：自动选项、多选结果、清除、保存恢复、旧内容格式兼容、
真实原生列表模板文字全部通过。`navigation-filter-filter-panel`：正常/小窗口布局通过。
`navigation-filter-navigation-roots` 与 `navigation-filter-tree-current-folder`：固定入口、
实际目录进入、当前目录高亮及视口保持通过。
