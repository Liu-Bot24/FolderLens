# 09｜M0–M8 开发顺序与退出条件

## 执行规则

planning/tasks.json 是可更新任务表，planning/requirements.csv 是范围基线，planning/acceptance.csv 是验收基线。状态初始全部 NOT_STARTED / NOT_RUN；任务有依赖，不根据文档行号自行并行。每一阶段按“阅读契约→实现纵向功能→反例测试→实机验证→更新证据和交接”的顺序完成。

不按日历估算冒充工期，不在阶段结束时例行询问是否继续。某条因真实环境限制 BLOCKED 时，继续不依赖它的任务；已实现但缺测试证据为 IMPLEMENTED_NOT_VERIFIED，不是 DONE。不能因为存在 BLOCKED 就停止所有工作，也不能声称总体 GO。

## M0｜环境、依赖、五个风险验证

先检查 Windows/SDK/MSBuild/C++ 工具链和适用 AGENTS，保留已有环境；建立 global.json 等锁文件。创建最小原生 WinUI 窗口、一个后台工作进程、一条真实图片显示通路，然后立即验证：

1. Release 自包含目录可在没有开发 SDK 的 Windows 上启动，Win2D 原生依赖齐全。
2. 真实 ARW 内嵌预览、LibRaw 原始开发、ICC/方向、61MP 内存行为；不只验证 JPEG。
3. HEIC/AVIF/JXL 的实际打包解码能力，以及 APNG/Animated WebP 的帧合成接口，生成运行时能力报告。
4. 百万行 SQLite 的筛选首批、稳定结果快照、深位置取页；写入并行时 WAL 有界。
5. 5GiB 文本首屏/跨4GiB定位和 WebView2 无全局运行时情况下的离线 Markdown 显示。

五项是独立的小型风险验证，不要求此阶段先做完整 UX。失败先修适配，不允许带着“以后会解决”进入大量业务 UI；不涉及失败点的工作可以推进。验证结果放 artifacts/m0/，缺真实 ARW 时写 BLOCKED，不能用改扩展名伪造。

## M1｜扫描、索引和真实纵向切片

完成核心模型、版本令牌、契约验证、IPC、目录枚举、批量入库和本地存储。窗口选择实际目录后，增量出现文件，点击真实 JPEG 有预览。接入 watcher/错误状态，能够取消扫描和切根目录；初版就测试无权限、UNC离线、长路径、Unicode、联接循环和退出清理。

退出条件：不依赖Mock即可“选根→发现文件→分页列表→预览→关闭”；源文件无写入；旧根任务不回写新根；部分枚举不误删索引；数据库可重建且设置保留。

## M2｜完整检索与列表产品化

完成类型、格式、RAW、动静态、尺寸、比例、体积、分配大小、日期、时长、名称路径查询；unknown/failed/inapplicable四值语义；保存视图；网格和详情切换；自然排序；路径显示；目录隐藏/不扫描双规则；稳定快照、左右序列和随机位置取页。

退出条件：SQL筛选与参考实现随机对拍；十万/百万目录不常驻全部VM；大偏移无深OFFSET；“索引尚未完整”可见；后台变化不突然换顺序。不要等全部图片组件完成才验证查询。

## M3｜图片核心完成

实现三条质量通路、原图100%、RAW开发、颜色和透明度、动画合成、多页TIFF、瓦片、相邻预取、全屏/只读旋转/幻灯片以及解码工作进程保护。当前选中任务优先，取消旧工作后旧结果被丢弃并释放内存。

退出条件：能力矩阵P1_MUST逐项通过真实样本；ARW明确区分预览与原始；在高DPI/跨显示器/损坏文件/快速切换中无错图和持续泄漏。没有样本或硬件的项目不得PASS。输出原图质量比对和性能记录。

## M4｜视频与音频查看完成

FFprobe有界分析、视频封面、外部播放器设置、系统打开和PotPlayer适配；按固定结果序列生成M3U8。支持内置单条音频试听及错误外部回退；不把内嵌视频偷偷加入范围。

退出条件：带空格、中文、emoji、引号语义、长路径的文件安全打开；实际PotPlayer验证顺序、UTF-8和从当前位置播放；未安装PotPlayer也能完成默认播放器路径。音频切换/退出不残留播放。

## M5｜文本与Markdown查看完成

有界窗口读取、增量行索引、编码、字节位置和搜索；单行超长、跨块编码、文件追加/截断；小Markdown安全富文本及明确的原文回退。先把真实大文本读通，再装饰编辑器视觉；不得先全文件ReadAllText。

退出条件：1GiB和5GiB真实文本可首屏/翻页/搜索/取消，内存有界；256MiB单行不会冻结；MD脚本/远程资源/路径逃逸不执行，超阈值原文仍完整可读。

## M6｜容量与会话闭环

目录直接体积与递归体积、同层占比/跨层排名、逻辑/分配、全范围/结果快照范围、未知统计和部分状态；文件变化增量更新；最近目录/视图/最后位置恢复；剪贴板、定位和外部编辑器；单实例和异常退出恢复。

退出条件：容量专用夹具和随机目录对拍精确；跨层不重复相加；离线与未知不当成0；清缩略图不清预设；复制路径和定位不修改源文件。

## M7｜系统级整合、性能和安全

在目标配置进行真实UI和原生解码测量；执行取消风暴、worker崩溃、WAL增长、磁盘满、网络中断、休眠恢复和长稳测试。完成键盘访问、高DPI、显示设备丢失/恢复，修复所有BLOCKER和MAJOR。

退出条件：强制功能、反例与性能硬门禁通过；日志无原文隐私泄漏；预算包括子进程；无任何“为了通过而跳过测试”改动。非参考机可提供测量，参考机验收仍标NOT_RUN。

## M8｜发布与可重复交付

锁定依赖，生成目录式便携包和每用户安装包；清洁离线Windows验证安装、运行、升级、卸载保留数据、Markdown与原生库；生成第三方通知/SBOM/哈希、用户说明、格式报告、测试和性能原始证据。

退出条件：从干净源码到可交付包的脚本重跑成功；便携ZIP不是开发机bin目录的随手拷贝；安装包没有遗漏native DLL/runtime。最终报告列全部需求和测试状态，给GO/NO-GO。GO仅指本次构建和被测试平台/样本，不扩张为所有相机、所有Windows版本。

## 子代理协作边界

主代理持有架构、契约和集成分支。可并行的域：已冻结接口后的图片Provider、文本Reader、容量纯算法、独立测试夹具。共享数据库迁移、IPC Schema、公共模型、包锁文件只能有一个写入负责人。子代理按文件所有权提交完整修改、实际测试与接口变更说明；不让多个代理同时改同一份Schema或全局包版本。

每次交接保留精确commit/工作区差异、未合并变更、已运行命令、失败复现、下一条可执行任务和测试夹具位置。上下文压缩后先读HANDOFF与任务表，不能把旧阶段的摘要当作当前通过证据。
