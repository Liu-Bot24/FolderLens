# 缩略图快捷收藏的显示与取消

用户实测指出星标始终显示，而且再次点击只能重复加入。原快捷入口确实始终调用添加；本批补齐取消分支，并将右上角按钮默认设为透明，仅在该按钮范围悬停或键盘聚焦时显示，离开或容器卸载后隐藏。透明时保留命中区域，使右上角仍可直接交互。

按钮采用 Windows `SymbolThemeFontFamily` 中的 FavoriteStar / FavoriteStarFill（E734 / E735），28 DIP 按钮、16 DIP 字形、4 DIP 圆角及距缩略图边缘8 DIP留白，替换常驻圆形白底。图标来源为[微软 Segoe Fluent Icons](https://learn.microsoft.com/windows/apps/design/iconography/segoe-fluent-icons-font)，不另画星形。

实心星代表存在收藏归属，再点从该文件所在的全部收藏夹移除；原文件、收藏夹及其他文件保持不变。取消后再次收藏沿用本次应用上次成功选择的目标；首次添加仍弹窗，取消已有收藏无需选择目标。右键和顶层菜单仍每次显示管理弹窗。

取消复用现有完整观察值检查，在单事务中按目录位置与文件键删除全部归属；不按收藏夹分批提交，也不受普通添加最多64个目标的限制。行在等待中换绑时不直接回写过时星标，继续有界刷新。

验证：2项新数据库用例通过，覆盖65个收藏夹、仅移除当前文件、再次添加、过期观察和预取消不改归属；测试仅使用小型合成数据库，结束后清理临时夹具。全量344项单元通过，应用Release构建0错误、7项NU1900警告。已有原生快捷收藏验证改为检查二次取消、再次添加、多归属清除及显示状态，但本轮未启动原生验证窗口，未声称物理鼠标、实际观感或焦点复验通过。
