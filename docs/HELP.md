# 使用帮助与已知问题

[返回 README](../README.md)

## 为什么列表中没有显示所有文件？

扫描过程中，文件会逐步出现在列表中。若扫描结束后仍缺少文件，请检查：

- 当前打开的文件夹是否正确。
- 顶部的文件类型、搜索条件和“查看层级”是否限制了显示范围。
- 文件所在目录是否可访问；网络位置或移动硬盘是否已连接。

文件夹内容发生变化后，可按 **F5** 刷新。

## 为什么某个文件无法预览？

不同文件格式、编码方式和系统解码器会影响预览兼容性。可先使用外部应用打开该文件，确认文件本身能够正常读取。

PDF、Office 文档和压缩文件目前支持分类浏览、查看属性与外部打开，不提供内置内容预览。图片及媒体的支持范围见 README 的[文件支持](../README.md#文件支持)。

## 如何更新程序？

退出 FolderLens 后，安装新版本或替换完整的便携程序包，再重新打开。更新前如需备份设置和收藏，可按 README 的[数据与隐私](../README.md#数据与隐私)说明备份数据目录。

## 如何切换主题？

在 **查看 → 主题** 中选择 **原生** 或 **柔和**。选择会自动保存，无需重启；两种主题均随 Windows 的浅色或深色设置切换。

## 如何在预览窗口播放视频？

选中视频后，点击封面中央的播放图标开始播放。播放后点击画面可暂停或继续，上方的播放/暂停按钮会同步更新。鼠标移入视频区域时显示进度控件，移出后隐藏；首次播放图标不会持续遮挡画面。若内置播放不支持该编码，可点击“外部播放”。

## 如何查看长图？

- **适应屏幕**：在完整显示整张图片与按窗口宽度显示之间切换。等宽显示时从图片顶部开始，适合从上往下阅读。
- **100%**：按原图实际像素显示，并定位到图片中心。
- **点击图片**：从完整显示状态放大到点击的位置，再点一次返回完整图片。也可用 **Alt + 滚轮** 上下移动长图。

小预览、窗口预览和全屏预览使用相同的缩放操作。

## 为什么 MP4 显示“仅音频”？

MP4 等媒体容器也可以只包含音频轨道。检测到文件没有视频画面时，会显示“仅音频”，这不代表文件损坏；带内嵌封面的音频仍可显示封面。

## 预览版已知问题

长时间连续切换文件时，内存占用可能持续增长，并影响运行流畅度。此问题尚未解决。
