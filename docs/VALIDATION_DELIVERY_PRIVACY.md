# 交付文件范围与本地数据隔离

安装脚本此前使用整个程序目录的递归通配符，和便携 ZIP 的发布清单方式不一致。发布前完整性检查会拒绝额外文件，但安装阶段本身没有相同的白名单边界。现在两种包均从经过校验的同一份清单取文件，安装包通过逐文件 Inno include 输入，不再递归收录目录。

路径校验拒绝数据库、备份、开发文件、越界、通配符、重复路径和重解析点；输入长度与 SHA-256 必须匹配。安装模式继续排除便携配置。默认运行脚本读取当前交付入口及构建标识，不再回退到另一份 bin 程序。

`scripts/Test-PackagePrivacy.ps1` 使用微型合成运行文件和私人数据库占位文本，确认仅程序文件被列入，私人文件、越界、通配符、备份、哈希不符和重复条目被拒绝，并检查安装脚本确实消费逐文件清单。原递归配置下失败，修改后通过。`scripts/Test-ReleaseRules.ps1` 的十个路径正反例与 PowerShell 语法检查通过。

本批没有生成安装包、执行安装或启动应用窗口；未对实际用户数据库进行迁移或复制。上述验证不代表干净机器安装、实际启动和焦点行为通过。业务程序集沿用启动迁移修复提交 `6901f76`，本批只变更交付脚本及说明。
