# 文件操作完成核对修复验证

日期：2026-09-23。基线：`0940dc828d16e7c553f02a4f660d1773b348e342`。范围为复审 F094-01、F094-02；F094-03 旧弱绑定升级仍按低优先级兼容事项保留。

## 原因与修复

- 拖出递归结果中的子目录文件时，原完成回调只核对当前浏览目录，没有携带数据包中文件的父目录。现在拖出会话保留已准备文件的源路径，完成后核对其已登记父目录。取消拖动可能多做一次单层核对，但不会修改原文件。
- 同一视图的新完成操作原先取消旧核对，只传递新操作目录，可能丢失旧操作尚未处理的目录。现在停止扫描后的完成核对使用同一视图的待办目录队列；每次操作加入需求，目录成功核对后才移除。扫描期间再次收到同一目录需求会重排到队尾再核对。导航退役旧视图队列。
- 内部 30 秒期限原先与导航取消一同被静默吞掉，部分数据库提交也没有发布。现在区分内部超时与视图取消；超时时发布已提交的列表变化、提示核对未完成，并保留未完成目录供下次操作核对或用户按 F5 主动刷新。旧视图取消保持安静。
- 核对仍严格限定已登记目录的单层范围，不重启停止的全范围扫描，不进入新发现的无关子树。
