# 10｜测试、验收与发布判定

## 1. 证据层级

Unit：纯函数/内存参考实现、日期/尺寸/排序/版本状态机。Integration：真实SQLite、目录和IPC，不依赖UI。Media：实际格式文件与真实native解码。UI：真实Windows窗口、键盘/鼠标、焦点和屏幕呈现。Performance：真实测量原始样本。Packaging：没有开发环境的干净Windows，实际安装/启动/卸载。

Windows UI自动化首选FlaUI/UIA3，元素提供固定AutomationId；工具对WinUI能力必须M0/早期验证。[S25] UIA不可见的GPU画布以状态接口+屏幕截图/像素比对补充，不拿纯逻辑Mock替代画面。自动化不能完成的色彩/显示器检查保留人工验收步骤和截图。

xUnit用于Core/Integration；FsCheck或等价属性测试用于筛选、自然排序、容量与状态机。各工具精确版本经M0锁定。正式日志保存dotnet test TRX或等价机器输出，不只写“通过N项”。

## 2. 夹具与隐私

固定fixtures/manifest.json列出fixtureId、来源/许可、sha256、字节长度、预期类型/尺寸/方向/帧数/位深/ICC、可公开性和所属测试。公开小夹具可入仓库；私人ARW、视频和文本仅存本地fixtures/private，gitignore且禁止上传。测试报告用fixtureId，默认不写绝对私人路径。

数据集：D1一万真实混合文件；D2十万目录混合；D3百万文件条目查询库+独立实际文件枚举集；D4真实高像素ARW；D5完整格式矩阵；D6真实1GiB/5GiB编码文本和256MiB单行；D7无权限/链接/硬链接/云占位/UNC；D8损坏媒体和恶意Markdown。合成索引用于数据库性能，不能冒充百万文件真实磁盘枚举；稀疏文件用于偏移边界，不能冒充5GiB有效文本读取性能。

大文件夹具由可复现生成器产生，记录seed与逻辑内容哈希；默认不一次创建百万小文件到用户素材盘，先征得测试路径授权和磁盘预算。不得用系统目录做破坏性夹具。

## 3. 必须有的反例

快速A→B→C后A最后返回；文件被同路径替换；metadata补齐改变排序键；删除当前项；重命名后旧缩略图回写；切根后旧scan批次到达；worker重启后旧pipe消息；取消后共享内存未释放；缩略图页重用到另一个文件。

网络断开误报空目录；枚举中途无权限；watcher缓冲溢出；watcher不可用；应用关闭期间目录变化；目录大小写敏感；排除foo不误排foobar；联接循环；硬链接；云占位不被批量取缩略图触发下载。

图片EXIF八方向、CMYK/ICC/alpha、16位、损坏/truncated、动画disposal/blend/loop、TIFF页与文件导航；纹理上限、DPI切换和device lost；RAW内嵌较低分辨率不可冒充100%原图。

UTF8多字节/UTF16代理对/CRLF跨页；GB18030四字节；4GiB偏移；未知编码；长单行；文件追加/截断；搜索跨块；取消旧搜索；MD链接/HTML/CSS/远程资源/符号链接逃逸、嵌套爆炸。

容量零字节/未知分配/硬链接/跨层重复/排除/直系文件/部分扫描、scope切换、旧版本增量补偿重复到达。SQLite锁/磁盘满/崩溃重启/坏缓存/迁移备份与回滚。

## 4. 需求追踪与状态

planning/acceptance.csv中每条都有req_id、测试层、步骤、期望和blocking。初始状态NOT_RUN，不因文档生成而改变。实现时可以拆成更多子用例，但不删除原用例及门槛。测试结果只有PASS/FAIL/NOT_RUN/BLOCKED/SKIP；核心P1的SKIP必须在总判定中视作未验收。

需求DONE要求其全部强制用例PASS且有实现文件/commit/证据；“编译通过但UI未测”不是DONE。每次改核心契约至少全量跑Unit/Integration，加受影响的Media/UI/Performance；候选发布需全部适用测试重新跑，旧构建的PASS不能自动沿用。

## 5. 性能验收

严格按docs/08采样并注明硬件/系统/GPU驱动/磁盘/显示器/DPI/软件和依赖版本、源文件集、冷热定义及并发后台任务。保存逐次时间与内存，P95/P99从原始数组计算，不手填漂亮数字。

功能测不出来的性能不能PASS。基准机无真实目标硬件时，跑现有环境的结果并明确参考机NOT_RUN；不能拿Linux SQL速度推断WinUI原图体验。性能软目标失败也必须给原因和优化说明；硬门禁失败必须NO-GO。

## 6. 源文件只读验证

在受控完整夹具上记录预览前后内容哈希、长度、mtime；使用审计/文件系统观察记录应用对素材目录的写入意图。LastAccess等系统维护属性单独解释，不把系统自身访问时间更新当成应用改内容，也不能借此忽略实际写入。缓存、WebView用户数据和播放列表只能写应用目录。

## 7. 发布判定

GO：P1所有MUST和强制用例PASS、所有指定实机/格式/性能/安装检查有证据、零BLOCKER/MAJOR、无未处理许可/依赖来源问题。NO-GO：任一核心项缺实现、FAIL、NOT_RUN、BLOCKED，或者只有模拟证据。可交付待验收构建，但文件名和报告必须标明candidate/unverified，不能当正式完成版。

每个缺陷包含等级、构建、复现输入、步骤、实际/期望、根因、修复提交、回归测试及复测证据。禁止为达GO把MAJOR改名为“已知限制”，或把真实原图功能改成外部打开。
