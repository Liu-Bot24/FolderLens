# 浏览状态切换与输入框对齐验证

## 行为约定

切换目录、文件类型或预览文件后，界面以最新操作为准。旧范围的扫描、目录树读取、查询、封面和预览任务应取消；已经返回队列的旧结果或错误不能覆盖当前内容。索引等可复用的数据与当前显示请求分别管理，避免取消显示时破坏后续阅读。

同一筛选条件刷新失败时，可保留仍然有效的结果；切换了筛选条件后，不能在新条件下继续显示旧条件的文件。非法筛选值应显示错误，并阻止旧查询重新填充列表。

## Markdown 退出恢复

内置与系统 WebView2 均复现过关闭最后一个控制器后，浏览器停留在退出阶段，使同一配置目录的下一次创建挂起。修复保留空闲 60 秒释放策略，等待原始初始化任务终止和对应浏览器退出事件，再允许重新创建。

超过退出等待时间时，只回收当前实例独占临时目录中、已验证来源并持有原始进程句柄的浏览器；不按进程名清理其他浏览器。恢复后仍须收到退出证据。无法确认退出时保留临时目录并报告失败。正常退出路径、需要恢复的路径以及另一独立配置目录不受影响均已验证。

## 验证边界

原生验证使用真实 WinUI 控件、独立数据目录与离屏窗口，不占用用户鼠标或前台。输入框渲染覆盖本机的 DPI 和上述四种主题组合，不代表全部显示器与缩放组合均已验收。

本报告只覆盖上述切换行为与相关回归，不替代长期内存、独立 Windows 环境、低内存机器或全部真实网络设备的验收。
