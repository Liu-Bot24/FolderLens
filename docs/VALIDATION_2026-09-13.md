# 文件浏览与审计修复验证

## 本批实现

文件夹筛选支持包含/排除、文件夹名称/相对路径、普通匹配/通配符/正则、子目录范围、启停、编辑保存取消、匹配预览及收藏视图。旧路径排除保留原有比较语义，不自动转换为有不同长度、数量和大小写限制的新规则。

文件浏览分类覆盖图片、视频、音频、文本、PDF、Word、Excel、PPT、压缩文件及全部文件。文档网格有文件类型标记，详细信息支持列宽、列选择和分类记忆。文本阅读提供清晰的返回入口、原文/排版、字号、翻页、查找与跳转；返回保留目录和选择。AI 辅助规则不在本批范围内。

## 已修复问题与回归入口

| 问题 | 修复与原生回归入口 |
|---|---|
| 首批结果重试/升级清空缩略图，选择阻断升级 | 稳定首批投影、身份保留、查询合并；`--verify-first-page` |
| 折叠组旁自动结构变化整表重绑 | 直接集合视图、正确的分组变更协议；`--verify-group-collapse`、`--verify-group-publication` |
| 全部折叠被当成空结果 | 以当前绑定的分组判定空状态；`--verify-group-collapse` |
| 隐藏文件夹在验证前修改筛选 | 候选先验证，失败保留原条件；`--verify-directory-filter` |
| 旧路径排除转换破坏兼容性 | 保留旧规则，支持查看和删除；覆盖 65 条、513 字符及大小写相近路径 |
| 相同规则的复选框修改错误行 | 按明确行位置更新；覆盖第二行关闭后与第一行相同、再刷新并启用 |
| 全部文件的几何条件漏掉视频 | 几何适用于图片和视频，再与类别相交；SQL 正负例与独立差分测试 |
| 收藏视图覆盖手动分类布局偏好 | 仅记录用户的视图按钮操作；`--verify-directory-filter` |
| 预览返回/适应屏幕文字被按钮固定宽度截断 | 自适应宽度及横向滚动；`--verify-text-reader` |

## 本地结果

- Release 构建成功；单元测试 230 项通过，0 失败、0 跳过。
- 首批失败两次后的卡片、容器和缩略图保留；升级保留选择、支持前后切图；失败历史持续保留且不含源目录完整路径。
- 折叠旁增删其他组保留当前卡片。小范围组移动保留可见容器和缩略图。
- 40,000 项批量更新观测 13 帧，空白帧为 0；只创建 256 个当前需要的文件行。
- 屏幕外新增 37,329 项：约 5.7 ms、约 184 KB UI 线程分配、0 个屏幕外文件行提前创建。这是本机夹具测量，不是所有设备的性能承诺。
- 综合用例覆盖目录历史、递归开关、缓存写入失败后的预览、快照租约、分离插入、组排序及缩略图任务保留。
- TXT/Markdown 原生阅读检查在正常 Windows 子进程权限下通过。受限沙箱阻止 WebView2 初始化时的超时另有失败记录，没有通过放宽文档脚本权限绕过。

原生用例通过应用的公共测试入口 `--verify-refresh` 加上对应专项参数运行；每次使用独立 `--data-dir`，生成自己的夹具和 `native-refresh.json`。测试数据、私人截图和原始日志不进入仓库。
