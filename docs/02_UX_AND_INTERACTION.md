# 02｜界面与交互规范

## 1. 布局

主窗口默认 1440×900 DIP，最小 1000×640 DIP；不得超出当前显示器工作区。首次按工作区裁切，后续恢复。支持 100/125/150/200% DPI 与跨显示器拖动。

顶部：返回、打开目录、路径面包屑、名称/路径搜索、扫描状态、刷新、设置。
左侧：最近目录/保存视图、可折叠目录树、当前类别筛选。默认宽 260 DIP，范围 220–420。
中间：图片/视频/音频/文本/全部标签，条件摘要，排序，网格/详情切换，虚拟化结果。
右侧：预览与属性，默认 380 DIP，范围 300–800；F8 显示/隐藏。窄窗口优先收起右侧而非使文件区不可操作。
底部：已发现/符合/待判断/失败数量、选中信息、空间统计状态、后台任务暂停。

默认跟随系统主题，预览背景独立默认深中性灰；透明棋盘格可开关。无需在每次扫描时做动画背景或视觉装饰。使用系统字体 Segoe UI Variable/系统中文回退，不下载字体。

## 2. 网格与详情

缩略图卡默认 180 DIP，可调 100–320。统一卡片高度和 image contain，**不得为了铺满裁掉图片边缘**。可选填充裁切视图必须有明显开关，默认关闭。文件名一行省略；底部格式、尺寸、时长等轻量信息；右下角相对目录路径默认开启并可隐藏。根目录直属文件显示“根目录”。

卡片有 RAW/动图/多页/视频/音频/离线/错误标记。动图和视频在网格不自动播放，悬停不触发媒体播放。可见缩略图解码失败显示统一占位符与可读原因，不无限闪烁重试。

详情视图使用虚拟化 ListView + 统一列宽的行模板和独立表头，不为首版引入未知维护状态的 DataGrid。列可排序，列宽可调整并保存；第一列文件名，至少包含路径、格式、尺寸、逻辑大小、分配大小、修改时间、时长。

列表与网格共享选择锚点。更新缩略图不重置滚动、不清空选择、不重建整棵可视树。计数和缩略图更新批量提交，快速滚动时跳过过期容器。

## 3. 三种预览模式

右侧预览：单击即加载当前文件，不自动播放音频/视频；图片先预览后足够当前物理视窗的清晰图。
沉浸查看：图片双击/Enter 打开；右侧面板隐藏，顶部显示名称、序号、格式、RAW/质量状态。Esc 回到原滚动位置。
全屏：F11 切换当前窗口全屏，不改变 Windows 分辨率；多显示器仅占当前显示器，退出正确恢复。

视频双击直接外部打开；音频双击开始内置试听；TXT/MD 双击进入扩大阅读视图。Space 在列表中切换快速预览，在活动音频/动画里切换播放暂停，文本输入框有焦点时不截取空格。

## 4. 图片交互

默认 Fit：图片完整放入可见区，不放大小于视窗的图片；另有 FillWidth、ActualPixels 100%。滚轮默认以指针为中心缩放；可在设置换为滚轮切换，但默认左右键导航。鼠标拖动平移；双击在 Fit/100% 切换；Ctrl+0 Fit，Ctrl+1 100%，+/- 缩放，R 顺时针只读旋转，Shift+R 逆时针。

100% = 一个源图像像素映射到一个显示物理像素，不是一个 DIP。DPI 150% 时需正确换算；原图内存里的 orientation 已处理，不再次旋转。

左/右键在 Fit 时切换文件，放大时仍切换文件，平移使用鼠标/Shift+方向键；Home/End 到首尾（快照 ready 时），无循环默认为止。幻灯片 Ctrl+Space 开关，默认 5 秒，只在图片会话有效；加载太慢时等当前图进入可用状态后计时，不连续跳过未显示图片。

切换文件默认重置 Fit；设置可开启保持缩放比例和相对中心。保持时不把旧图绝对坐标套到新图导致画面飞出。多页 TIFF 用独立页控件和 PageUp/PageDown；左右仍是文件。动画显示播放暂停、当前时间/帧进度，不能把每帧变成文件列表项目。

## 5. 文本与容量

文本阅读器显式显示编码、原文/渲染模式、加载范围、搜索进度；长行截断的是本次屏幕布局而不是永久丢弃内容，有“继续此行/跳转字符位置”。复制只复制已明确选择的范围，不隐式加载整文件。

容量页：顶部范围“整个已扫描目录/当前筛选结果”；口径“逻辑大小/分配大小”；主区同层目录条形占比和排名，右侧文件/未知/错误明细。点击目录下钻，返回保持上一层排序。

## 6. 通用快捷键与无障碍

Ctrl+O 打开目录；Ctrl+F 当前文档内搜索（阅读视图）或文件搜索（列表）；Alt+Left 返回；F5 刷新当前根；Esc 先关闭弹层/退出全屏/退出沉浸，不直接退出应用；Ctrl+Shift+C 复制完整路径；Ctrl+L 聚焦路径栏；F1 打开本地帮助。

所有可操作元素有 AutomationId、中文可访问名称、焦点指示和键盘路径。AutomationId 稳定供 UI 测试使用。不要让全局快捷键吞掉输入法候选、搜索输入、文本选择和 WebView2 内复制。

## 7. 空态与错误文案模板

- 尚未打开：“选择一个文件夹，查看其中及子文件夹内的内容。”
- 无匹配：“当前条件未找到已确认符合的文件。”有待判断时追加其数目，不说目录为空。
- 离线：“原位置暂时不可访问，当前显示缓存记录；不会删除索引。”
- RAW 预览：“相机内嵌预览；正在加载 RAW 原始分辨率。”
- RAW 降级：“RAW 渲染失败，目前为内嵌预览。”保留重试/外部打开，不能显示 FullReady。
- 分配未知：“该位置未提供可靠分配大小。”不能显示 0 B。
- 超大 MD：“已使用大文件原文模式，内容未截断；富文本渲染已停用。”
- 外部播放器失败：显示实际 exe 或系统关联问题，提供设置入口，不重复拉起进程。
