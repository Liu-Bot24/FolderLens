# 06｜视频、音频、TXT 与 Markdown

## A. 视频：内部浏览，外部播放

### A1. 探测与封面

FFprobe 获取 container、主视频轨、显示宽高、coded宽高、旋转、SAR/DAR、duration、codec、bitrate、frameRateRational、hasAudio、HDR 标志；ffprobe 的结构化输出可用于媒体探测。[S16] 不把平均帧率为0/未知转成0fps真值；可变帧率显示 VFR/平均值。音频封面轨 attached_pic 不当作普通视频轨。

默认视频主轨：排除 attached_pic，优先默认轨，其次最大有效画面轨；多个视频轨在属性中列摘要。未知时长和损坏头信息可重试，不能令目录扫描终止。

封面先使用可信内嵌封面，没有则提取视频约10%处，最长不超过30秒；短于2秒使用接近开头有效帧。第一目标失败最多再尝试首个可解码帧。**不为找漂亮画面扫描整段视频**。封面最长边512px/按DPI需要1024px，缓存带选帧策略版本。

FFmpeg/FFprobe 仅使用本地普通媒体容器，关闭远程协议和外部资源加载。拒绝 m3u/pls/concat/脚本作为待探测媒体，不让本地列表文件触发网络或读取其他未经授权文件。参数通过 ArgumentList 分项传入，绝不用 cmd.exe/powershell 拼接命令。stderr/stdout 必须并行有界消费，防管道阻塞；输出JSON上限4MiB，封面任务默认15秒超时，可取消并终止进程树。

一期视频封面默认软件解码并发1，避免启动GPU上下文争抢显示；是否改硬解仅凭实际基准并保留回退，不要求用户安装CUDA工具包。视频完整播放性能由外部播放器负责，应用不承诺改善它的解码能力。

### A2. 外部播放器策略

播放器选择优先级：用户指定可执行文件 > 已检测到且用户选择的 PotPlayer > 系统关联。首次无需必须安装 PotPlayer；可检测用户/系统安装注册信息和有限常见路径，不扫描全盘、不自动下载安装播放器。

设置包括 exe路径、显示名称、单文件/播放列表能力、经过验证的参数模板。默认自定义EXE只传一个绝对文件参数，不允许任意shell表达式。模板只支持受控占位符 {file}/{playlist}，不能执行子命令。

系统关联通过 Windows Shell 打开单个本地文件；自定义exe通过UseShellExecute=false+ArgumentList。打开前验证仍是同一文件项，文件不存在/权限失败/关联为空提供可操作错误。外部播放器的当前工作目录设为其安装目录或安全目录，不设为素材目录，避免DLL侧载。清理会破坏外部程序的本应用私有runtime环境变量。

### A3. 当前结果集播放列表

显式命令：
“打开此文件”：单文件，不假定外部播放器后续项目来源。
“从当前项继续播放”：从固定结果会话的当前ordinal起，保留原排序的后续video项目。
“播放当前结果全部视频”：从第一个video开始。
“播放选中视频”：按结果ordinal排序，不按鼠标点击先后。

生成受控本地 .m3u8（UTF-8；BOM策略在PotPlayer实测确定并锁定）或具体适配器验证通过的格式。条目必须为本地绝对路径/UNC，不允许远程URL和控制字符。逐条输出而不是超长命令行；超过10,000条不一次发送，分段并明确界面播放范围，不暗中遗漏。

PotPlayer直接接受文件/列表路径的能力和编码必须做真实测试；不得凭记忆发明 /playlist-start 等命令行参数。采用“从当前项开始的子列表”避免依赖未经验证的起播索引选项。系统默认播放器未验证列表支持时此命令置灰，仍可单文件打开；用户指定支持的播放器后启用。

列表需会话Ready；Building状态允许等待/取消，不能把已构建的前512项当完整结果。外部进程退出不一定代表播放完（可能转发给已有实例），所以临时列表保留至少24小时，在后续启动清理过期文件，不启动后立刻删除。应用退出不关闭用户播放器。

## B. 音频：轻量内置试听

使用Windows.Media.Playback.MediaPlayer，Windows官方支持在WinUI中通过MediaPlayer/MediaSource播放本地媒体。[S17] 一期不引入libmpv，仅保留IPlaybackAdapter边界供后续视频内嵌。

强制测试MP3、PCM WAV、FLAC、AAC/M4A常见编码；OGG/Opus/WMA等按系统实际支持报告，失败外部打开。音频元数据和封面由同一FFprobe/FFmpeg受控管线提供。无封面显示音频图标，不为每个文件生成全长波形。

单击选中只显示信息；点击播放/双击才开始。提供播放暂停、拖动进度、已播/总时长、0.5/1/1.25/1.5/2倍速、音量、静音。切换文件、切根或关闭预览时停止旧音频，防幽灵播放。默认不连续自动播放；开启“连续试听”后只沿当前结果的audio子序列。

MediaPlayer事件带当前sourceGeneration，旧Opened/Failed不能覆盖新音频状态。设备断开/切换、文件被删、播放失败可恢复；即使无音频设备也不能卡住浏览。对不可seek的格式禁用拖动并说明，不能显示进度已跳转但实际没变。全局快捷键不得劫持文本输入。

## C. 文本：统一的有界阅读器

### C1. 支持与默认值

TXT、LOG、CSV、JSON、XML和常见代码文件作为原文，只读；MD/Markdown另有富文本模式。其他文件先做小范围二进制检测，不能把所有二进制强行用UTF-8读出百万乱码。

所有原文文件都使用同一个分页Reader；小文件可以被页缓存完整覆盖，但禁止为大文件换成ReadAllText。支持UTF-8(BOM/无BOM)、UTF-16LE/BE、GB18030/GBK/本地代码页可选。BOM优先，严格UTF-8样本判定其次；未知编码给出编码选择，不自称百分之百识别。中文编码通过Encoding.RegisterProvider和锁定的System.Text.Encoding.CodePages实现。

初始读取256KiB，页窗1MiB，原文字节缓存32MiB，解码文本缓存32MiB，最多约2,000个可见/预取布局行。边界数值是配置默认值，不是截断文件内容。

### C2. 文件与分页

使用64位字节offset、FileStream随机读取或经实测的分段MemoryMappedFile；网络优先FileStream，避免映射远程超大文件。不能映射后把完整view复制成字符串；不可把2GB以上offset强转int。

UTF-8/GB18030跨块字符、UTF-16奇数字节/代理对、CRLF跨块必须保持Decoder状态或对齐重读。滚动到任意字节位置时找到合法字符/行边界，显示“约xx%位置”；不知道精确行号时显示索引建立中，不捏造行号。

逐步建立稀疏行索引：每1MiB或约4096行一个(byteOffset,lineNumber,decoderCheckpoint)，采用磁盘索引并有界内存；精确行号跳转到未索引区域时后台建立到该位置并允许取消。所有索引绑定fileVersion+encoding，编码改变/文件截断后失效。

超长单行按最多32,768个Unicode字符的可视片段排版；下一片段可继续阅读和选择。默认大文件不自动换行；用户开启后对当前窗口排版，不能全文件重新布局。普通文本页可以用只读控件，但控件永远只接受已限定的窗口文本，不承载整文件。

复制限制默认16MiB字符数据，超限明确提示缩小范围；Ctrl+A在原文表示整个文档选择意图，不立即物化全文，超过复制上限不偷偷截断。预览器不写文件；保存按钮不出现。

### C3. 搜索

当前文件全文搜索为流式，不是只搜已载入页面。默认文字字面量，支持区分大小写开关；不做用户正则，避免灾难性回溯。搜索使用与当前编码一致的增量Decoder，保留足够的跨块匹配状态和源字节位置，保证跨块中文/代理对/长关键词命中。

默认上限10,000个展示匹配，达到后停止并显示“已显示上限，尚未遍历完整文件”，允许用户缩小条件；不得显示“总共10,000”。搜索结果每批最多100条，前100条即可交互；取消默认100ms内反映在UI，底层分块读取结束后停止，网络不可取消时终止隔离读取任务。

搜索取消/换词/换文件需queryGeneration及fileVersion检查；晚到结果不能追加到新搜索。文件修改/截断时提示“文件变化，重新加载”，不继续用旧索引返回错误位置。日志实时tail不在一期。

### C4. 大文件门禁

至少验证1GiB和5GiB真实生成文本、GB18030中文、UTF-16、256MiB单行以及跨4GiB定位。可使用生成器构造但必须真的写出内容；稀疏零文件只能测offset不能代替文本读取吞吐测试。

目标：本地SSD的1GiB文本首屏P95≤500ms，5GiB≤800ms；超过阈值不应导致UI阻塞；文本子系统常驻增量内存≤192MiB。详见性能文档；这些是门禁目标而非已测结果。

## D. Markdown：安全、有界、可降级

### D1. 路由

≤8MiB且初步行数≤50,000进入Markdig处理；配置普通CommonMark/GFM表格、列表、任务列表、链接、引用、代码块，不默认启用所有扩展。>8MiB直接原文模式，内容依然可完整分页阅读。

解析在Content Worker，3秒期限、最多100,000 AST节点、输出HTML≤16MiB；越限终止并转原文。WebView2导航首个稳定内容默认5秒期限，超时销毁该预览实例再转原文，不无限阻塞；记录具体超限原因。阈值以下也可能结构恶意，所以不只按文件长度判安全。

原文/渲染切换保留当前位置近似锚点；大文件不显示不可用的“强制完整渲染”按钮。一期不做Mermaid、LaTeX外部插件、脚本图表和网络字体。

### D2. 内容安全

Markdig禁原始HTML，输出再通过受控结构/链接政策；JavaScript关闭、无host object、无任意web message bridge；CSP default-src 'none'，仅允许自有样式和经应用批准的本地图像资源。WebView2的宿主需显式限制导航与特权接口。[S18]

相对图片只允许当前根目录内实际目标，经过路径规范化、解码和最终句柄目标校验，拒绝..、UNC外跳、重解析点逃逸、file/http/javascript/data URL等不授权资源。通过虚拟origin和应用资源路由按token供应，不把整个磁盘映射进WebView2。图片走应用的安全缩略图/预览管线，限制数目（200）和累计解码像素，防Markdown嵌入大图拖垮WebView。

外部http/https链接仅用户点击后交系统浏览器；默认不自动请求。引用本地MD/TXT可经确认的根内导航在应用打开，其他文件走显式外部打开；禁止脚本/可执行文件自动执行。锚点链接留在本页，不重建整个WebView。

### D3. Runtime与释放

同一时刻最多一个活动WebView2控制实例，切换纯图片不创建；空闲60秒释放不再需要的实例，保留用户滚动锚点。Runtime使用Evergreen优先，完整离线发行包带Fixed Version兜底，详见交付文档。[S20]

缺失runtime/组件损坏时原文始终可用，状态明确。正式完整发行包必须验证全新机器离线Markdown渲染；不能用“总能看原文”代替其安装完整性门禁。
