# SMB 兼容修复与可选主题验证

## SMB 故障证据

Windows 可以读取两个 SMB 盘，旧程序却在目录枚举前抛出 `DirectoryChanged`，未产生文件批次。句柄探针确认 `FileBasicInfo` 和旧式文件信息成功，而 `FileIdInfo` 返回错误 87。该故障属于文件标识兼容性回归，现有证据不支持权限丢失或重启电脑作为修复。

修复后同一组只读路径均返回 `started → batch → completed`：映射盘和对应 UNC 各 33 个根级条目，第二个映射盘 2 个根级条目。直接枚举和真实扫描工作进程均通过；未递归扫描整个网络盘，也未修改网络源文件。私人地址仅保留于被忽略的本机证据。
