# 后台发布固定数值滚动位置，当前目录信息常驻

日期：2026-10-12。依据：用户对 fa84971 实测后仍报告跳动，并明确要求新增前序内容时旧内容自然下移、滚动条位置不被带走；同时要求目录名称和容量固定显示，跨目录时更新。

后续修订：2026-10-13 用户实测要求正在浏览、已经单击选中的图片不得被加载挤出视野。本文“始终固定数值偏移”的部分由 [保护正在浏览的内容](2026-10-13-preserve-browsed-content.md) 替代；未操作的新目录仍保持顶部，固定目录栏保持原设计。

本决策替代 `2026-10-12-viewport-first-browsing.md` 中“开始浏览后保持文件锚点”的滚动政策。上次实现与静态审查没有完整满足用户实际意图，不能继续以旧文件仍在原屏幕位置为成功标准。

## 滚动规则

- 后台扫描发布保留列表的数值垂直偏移。新目录为 0；内容按原筛选与排序插入，旧内容可以向下移动。禁止为追随旧文件调用 ScrollIntoView。
- 选中文件与浏览位置是两个状态。点击当前可见图片可撤销待完成的历史恢复，但不因此放弃顶部或现有偏移。只有明确滚轮、滚动条/触摸拖动、键盘导航、指定文件定位等才交接滚动控制。
- 详情 ItemsStackPanel 显式使用 KeepScrollOffset。网格保留虚拟化 ItemsWrapGrid，通过一份绑定到视图、ItemsSource、根版本和交互版本的数值位置记录，处理后续 LayoutUpdated/ViewChanged 调整；不能把一次 ChangeView 当作所有延迟布局都已结束。
- 纠正请求合并到 UI Dispatcher；已经到位时不发 ChangeView，不用定时轮询。关闭、换根、换视图、源替换、显式移动使旧归属失效。
- 用户滚动尚在进行时，后台查询可以继续准备，但不得发布列表替换。等待手势结束和 180ms 静止窗口后合并发布；首批提升、普通发布及增量发布在进入同步操作前都检查该条件。该计时器只用于手势结束，不周期性纠正滚动。
- 指定文件取页可以很慢，因此真正设置选择和 ScrollIntoView 前重新接管滚动。全屏/沉浸返回也接入同一交接；不得读取隐藏列表的旧位置来重新声明顶部。
- 显式折叠完成投影/布局后采用当前可达偏移。下一批捕获也先按此前视图范围夹取，防止不可达旧偏移随着后续新增内容自动追涨。
- 点击折叠按钮会先结束尚未静止的旧滚动，再提交折叠后的偏移并继续待发布批次；为指定文件自动展开目录不走该交接，仍由文件导航决定最终位置。
- 保存视图/前进后退仍允许显式按历史文件定位，新用户操作仍撤销过时恢复。

官方依据：Microsoft 的 [ItemsStackPanel.ItemsUpdatingScrollMode](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.controls.itemsstackpanel.itemsupdatingscrollmode) 文档区分了保持首个可见项目与保持距离列表开头的偏移，后者对应用户此次要求。位置调整使用 [ScrollViewer.ChangeView](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.controls.scrollviewer.changeview)；显式导航仍保留 [ListViewBase.ScrollIntoView](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.controls.listviewbase.scrollintoview)。这些 API 说明不是本机已完成运行复现的证据。

## 固定目录栏

- 名称、容量、匹配数和本组文件数在列表上方独立一行常驻，占据自己的 60 DIP 高度；不能覆盖缩略图，也不随图片滚出屏幕。
- 根据实际可见的文件或目录标题确定当前目录，在进入下一目录时更新。折叠组只有标题时也能定位；旧根、旧组及隐藏视图的容器不能作为依据。
- 固定栏沿用当前组容量口径和部分统计标记，不另外扫描文件、不为判断目录读取屏幕外页。按 ordinal 二分找组，只检查已实现的少量容器与标题。
- 原来的目录分隔标题保留，便于识别组边界。固定栏提供同样的展开/折叠和目录菜单；这些明确用户动作撤销旧历史恢复。
- 分组还未形成的首批列表显示可见文件的目录和“正在整理目录容量和分组”，不编造容量。未启用分组、收藏集合或没有有效结果时隐藏固定栏。

准备回归：十万前序插入/移除保持偏移；首批提升保持 0 且点击不放弃顶部；延迟原生锚定不能抢回位置；新用户滚动可覆盖旧纠正；折叠后的目标收敛；固定栏无覆盖且跨组更新。
