# 文件观察与按需读取的一致性

目录扫描和收藏位置验证都可能观察同一个文件。二者共用基础属性写入逻辑；文件签名变化时，尺寸、时长、格式、拍摄时间和字段状态一起失效，再由实际需要这些信息的操作读取。

临时目录数据库的 schema 8 增加 `observed_revision`。它记录全局实际观察顺序，区别于每一条记录自身的 `file_version`。收藏存在多个目录绑定时选用最后观察到的记录，不比较不同行的局部版本号。收藏仍保存位置映射，复制、新增文件不改变收藏；移动和改名不跟随目标。

持续的文件系统事件采用 300 毫秒防抖，并在首项等待 1.5 秒后开始交付，每批最多 128 个目录，避免文件持续写入时无限等待安静期。

缩略图缓存命中后仍可能被系统解码器判定为损坏。只在确定的编码错误下使缓存键失效，释放读租约后清除并重新生成；其他读者持有租约时不再分发该坏键。取消、内存不足及设备错误不视为缓存损坏。

分组展开/折叠保存原始文件序号选区，再映射到新的可见区间，不遍历或实例化整组文件。隐藏的选中项取消选择，防止下一次文件操作作用于不可见目标。

Windows StorageItems 文件传输按页准备，不同时保留全部快照记录、操作目标和系统对象。单次最多 10,000 项，路径及对象开销预算 32 MiB，准备时间 30 秒；超过限制明确要求分批处理。每次分页和异步解析前后检查选择与来源是否仍有效，选择变化会取消整个数据包，不提交部分选择。

音视频属性与封面读取使用不可变源签名，在读取前、属性完成后、封面完成后和缓存写入前核对源文件，过时请求不发布结果。图片与文本工作进程在打开时检查 Offline/Recall 属性，只有当前请求携带明确授权才允许读取。

验证覆盖数据库迁移、收藏筛选变化、连续目录事件、真实 WIC 损坏 PNG、分组选区、文件数据包取消、真实 FFmpeg 读取期间变化，以及真实工作进程的 Offline 属性授权。Offline 属性夹具不等同于真实云盘提供方；云盘实际下载行为及检查和打开之间的竞争窗口仍需要提供方环境验证。实际 Explorer 鼠标双向拖放和系统剪贴板所有权尚未完成手工验收。
