# 收藏验证、资源重试与快照范围

Pro 对 `3451b7c` 的审计指出：收藏入口等待全部源路径探测；前台媒体绕过版本检查；Markdown 瞬时加载失败不再重试；BMFF 只看主品牌；小目录快照复制整根目录；ZIP 验证未证明条目集合与嵌入清单一致。

收藏首先建立可取消的导航状态，再验证并发布首条结果。后续每批至多 64 条，处理超过 250ms 时停止收集本批；单次探测限 5 秒，整次验证限 2 分钟。预算耗尽明确提示，未核实链接保留。应用通过同一有界查询发布路径刷新，导航取消和根代次仍拒绝旧结果。父目录探测在一批内复用，但在应用该批观察之前再读取一次；状态、物理身份、解析位置、卷身份、大小写模式必须一致。这样既减少重复 I/O，又拒绝“目录被替换，但原文件移回后身份不变”的反例。每次文件操作仍执行已有的实际源身份校验。

前台媒体复用 `ReadCover`，把优先级显式传给探测和提取；源身份在探测前、探测后、封面提取后及位图发布前校验。无封面音频仍校验探测前后版本。取消或切换后不发布旧内容。

Markdown 由宿主记录每个资源的失败及重试时间；瞬时 I/O、超时和队列饱和最多退避重试三次。权限拒绝、非法内容和已证实的源变化不重试。文档脚本、消息、宿主对象及远程资源仍禁用；原有 16 请求、2 解码并发、15 秒期限及缓存额度保持。导航撤销资源身份和取消令牌，迟到响应和退避均不能恢复旧文档。

BMFF 在最多 64KiB 的 `ftyp` 中解析主品牌与兼容品牌，检查普通／扩展长度、截断和排列；`mif1` 与兼容 `avif` 按 AVIF 路由。未知 BMFF 不默认认作 HEIC，`avis` 明确拒绝，符合一期不承诺动画 AVIF 的范围。

目录快照只保存所选子树及祖先，保持原有事务、分组与历史租约约束。ZIP 验证要求规范化且不区分大小写的条目唯一集合与预期集合完全一致，并校验唯一嵌入清单与外部清单的字节哈希；包外层哈希继续验证。

另有长稳发现的音频事件保留问题：停止播放器前解除四个原生事件订阅。100 个播放器的弱引用在正式长稳结束后均释放；剩余私有内存增长继续单独定位，不能由此推断整体无泄漏。
