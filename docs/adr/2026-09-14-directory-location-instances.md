# 目录位置实例与收藏归属

根改名后，父目录和文件物理身份可能不变。仅使用 v5 文件摘要会使新路径继承旧收藏；旧路径不可访问时，直接清除又会误删有效收藏。实际扫描反例覆盖了这两种情况。

catalog v7 将收藏身份改为目录位置实例与 v5 文件摘要的二元组。目录绑定持久化，包含修订号。只读元数据提供的已解析位置与目录身份都一致时，重叠根可以共享实例；不能确定关系时保留各自实例。确认失效的实例不再复用。不同名称的硬链接仍由摘要区分。

迁移先备份，再按旧成员 entry_id 的目录锚点转换，不能向全部同物理摘要的行扩散。迁移不重新计算 Files.location_key，不枚举源文件。旧版本拒绝 v7 数据；回退使用备份。

sessions v5 增加目录位置与绑定修订观察。所有收藏查询、状态、稀疏选择和提交都使用完整二元组；提交事务同时核验绑定。保留视觉对象时更新权威观察，旧快照缺乏绑定证明则不能修改收藏。

确认移动只清除旧实例，新位置由用户显式建立的收藏保留。确认同位时在短事务内合并成员并更新绑定；文件系统探测不持有数据库事务。无法访问、离线及不完整扫描不是删除依据。

验收包括未知旧位置与新位置的独立收藏、后续确认的两条路径、重叠根、深层目录、重启、旧选择拒绝、非空迁移和取消回滚。此 ADR 不声明实现已验证或发布通过。
