# 保留已接受的浏览状态与停止终态发布

对 1ea8a7d 的 Pro 复审确认三个剩余问题，采用局部修复，不改变目录穿透、首批 32 项、RAW 快速预览、临时库与缩略图预算。

- 新根接纳前保留结果源、快照句柄、首批行与已接受的根身份。身份核验及最终预算检查通过后才清理旧显示、修改地址/收藏范围和历史。晚到拒绝恢复原地址并解除替换状态，原观察 epoch 仍可查询；不伪造新 epoch 的文件观察。
- 显式停止捕获当前扫描任务、CTS、根版本、导航请求和停止修订；等待任务退场后，用应用生命周期下的独立查询发布已提交结果。该查询不重新扫描、不依赖进度节流。新导航、再次停止、退出及锁定的查看序列使旧发布失效。后台取消不会自行解除停止。
- 快照仍先 PASSIVE。WAL 达到高水位时尝试 busy_timeout=0 的 TRUNCATE，结束后恢复原超时。读者尚在则记录返回 busy 并保留大小限制；下一次快照再尝试，不在扫描 writer 上等待读者。禁止手动删除 WAL 或取消磁盘预算。

验证：新 WAL 回归在旧实现上真实失败为 CatalogWalLimit 对应的 IOException；修复后通过，包含持有旧读事务时高水位维护不堵写队列、释放读者后不靠额外业务写入即可生成快照。停止发布测试走生产协调函数和真实 SQLite，覆盖 2/31 项、等待退场、切根、退出反例。全量 434 测试通过，Release 编译通过。

原生验证追加晚到预算拒绝保持同一结果源、句柄、epoch，并可继续筛选；仅编译，未运行，不等同实际 F5/全屏/关闭交错验收。原生 UI 禁止批量抢焦点的约束继续遵守。无需重复测试已由用户确认的 RAW 或把源码结论外推成播放器性能验收。

FastStone 本机研究另存本地报告。新增对比、布局、缓存管理等产品变化须用户确认，不包含在本修复内。此次新改动尚未再次得到 Pro 通过结论。
