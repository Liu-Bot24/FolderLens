# 文件夹规则与通用文件分类

日期：2026-09-13。状态：已采用。

## 约束

文件夹筛选须支持精确名称、相对路径、包含/排除/保留例外和高级正则，切换规则复用索引；百万文件场景不能逐文件运行正则。原有 FilterSpec 收藏必须继续可读。

## 决定

FilterSpec v1 增加可选 directoryRules、extensions，缺省均为空，既有字段和扫描排除语义不变。DirectoryRuleSet 编译规则；SQL 使用不相关 IN 子查询在 Directories 上计算匹配集合，再通过 directory_id 筛选 Files。首屏、快照、分组与预览使用同一规则实现。加入扩展名条件用于 PDF/Office 等没有媒体元数据的文件，不新增媒体解码类型或要求先补元数据。

视图规则不参与扫描策略比较；skipScan 单独保留。正则限制长度/数量，采用 .NET 非回溯引擎及超时，拒绝不支持的结构而非绕过失败。界面明确不区分大小写。

目录规则、类型分类随既有 SavedView 保存；当前运行期间记住各分类视图模式，不在扫描增量中自动切换布局。对旧 hideView 规则在编辑界面转换为等价路径排除，应用前保留原草稿，取消不修改条件。

## 证据与限制

DirectoryRuleTests 覆盖正反例、例外优先级、停用、无效正则、SQL 首屏/快照/分组/预览、JSON 往返与未解码文档。10,000 文件/1 目录的 SQL 计数反例确认只调用一次目录匹配。原生目录编辑验收覆盖添加/停用/预览/应用且 epoch 不变。高目录数量、复杂规则组合在不同存储设备的真实耗时仍需纳入完整性能验收。
