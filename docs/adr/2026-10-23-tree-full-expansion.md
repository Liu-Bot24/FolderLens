# 目录树完整展开，取消分页

## 背景

目录树此前每层最多显示 128 个子文件夹，其余以“上一页/下一页/第一页/最后一页”伪节点翻页，目的是限制树节点数量。实际使用中翻页节点混在文件夹之间，难以操作，也不符合“展开即显示全部子文件夹”的预期。

## 决策

- 展开文件夹即显示全部子文件夹，不再有翻页节点。目录清单仍在后台按页从磁盘读取，只保留名称；读取完成后即释放清单文件。
- 首次展开较宽的文件夹时，先在折叠状态下填入子节点再一次性展开：WinUI 树在已展开节点下逐个插入的开销随可见节点数增长，折叠填充避免了平方级耗时。
- 已展开节点的刷新按 256 项分片合并，分片之间以低优先级让出 UI 线程；较新的清单或导航使旧合并在下一个分片边界停止，合并结果幂等。
- 保留原有的请求序号、导航取消、选中项恢复和选中祖先链补位。

## 验证

12,001 个兄弟文件夹（物理读取与索引读取）完整显示、顺序正确，约 0.6 秒完成，UI 最长停顿约 30 ms；改动前同样数据的分片插入耗时约 25 秒、最长停顿 1.4 秒。较早清单晚完成、合并中途被新清单打断两种竞态均只留下最新结果。超大文件夹仍会占用与子文件夹数量成正比的树节点内存。
