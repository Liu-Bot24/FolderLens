# Windows Shell 文件操作与收藏独立验证

文件管理改为调用 Windows `IFileOperation`，由系统处理复制、移动、回收、冲突提示、进度和撤销记录。应用只提交请求并核对结果，不自行再执行一轮复制或删除。

缩略图、详情列表共享多选捕获和标准 `StorageItems` 数据包，用于剪贴板及与资源管理器的双向拖放。拖入按卷身份选择默认效果，同盘移动、跨盘复制；Ctrl/Shift 显式选择复制/移动。创建快捷方式的拖放效果暂不支持。

操作对每项区分完成、原文件仍在、未完成和无法确认。仅复制成功不能代表移动成功，取消或部分失败不能通知剪贴板来源整批移动成功。大小写改名由 Shell 执行，并验证最终目录项拼写。

文件操作不写收藏映射。收藏在统一的位置校验中处理来自任何应用的文件变化；新增或复制不改变原收藏，确认原位置改名、消失或被替换才移除对应映射。未知、离线与权限错误不当作删除。旧操作日志读取保留兼容，新操作不产生该日志。

后台结果发布可能替换句柄但保留选择。提交操作前重新解析当前选择并比对条目、版本、位置、身份和文件时间大小；不使用句柄对象引用作为文件改变的证据。

验证：468 项单元与集成测试通过，包含真实 Shell 大小写改名、跨卷复制/移动、同目录生成副本、冲突、取消、收藏新增/复制不变与改名失效。WinUI 原生控件验证通过两种列表的多选复制剪切粘贴、延迟数据包、真实改名后关闭、待处理改名对话框关闭及属性请求退场。实际资源管理器鼠标拖放、系统剪贴板往返、目录选择器待处理退出尚未实测；自动化数据包验证不替代这些项目。
