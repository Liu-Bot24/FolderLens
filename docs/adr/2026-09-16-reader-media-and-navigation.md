# Reader media and directory navigation

Child navigation reuses the parent scan, but its address and selected tree node must represent the browsed child while its query is pending. Root-level progress is explicitly labelled when browsing a child. A tree listing obtained from the filesystem replaces the node's catalog routing metadata as well as its children; otherwise re-expanding an ancestor can restore stale indexed siblings.

Root admission keeps the accepted monitor and background-scan owner until the new identity is accepted. Refusal restores the cancellation context. Completion while admission holds the root gate transfers the old monitor to the accepted view, rather than disposing it prematurely.

Markdown rendering returns a token map without resolving or decoding all embedded resources. The body navigates first. The host checks at most 200 media elements every 200 ms while visible and assigns approved URLs near the viewport. Document JavaScript remains disabled; a host-owned IntersectionObserver callback did not execute in the tested configuration, so visibility checks use host ExecuteScriptAsync calls. Remote resources, raw HTML, host objects and web messages remain disabled. Hidden videos pause; remote images and path escapes remain denied.

Images retain the isolated path probe and decoder, two resource slots, a 16-request admission bound, a 15-second deadline and a 32-image/32-MiB host cache. Distant image elements drop their source while preserving intrinsic size. Video uses preload=none and the existing content worker for reads of at most 256 KiB. Every range revalidates the original source signature, including the actual open handle before and after reading; no local directory is mapped into WebView2. The worker's process timeout and cancellation also cover network source reads. Supported containers are MP4/M4V, WebM and OGV, subject to WebView2 codec support.

The text reader scrolls within its current bounded window before loading the adjacent window. Back exits immersive preview first. Reader file/page controls share one row, and the empty-state region starts below the measured details header.

Validation: 506 unit/integration checks passed; isolated native checks exercised refusal plus external changes, scan-completion ownership, long-text window round trips, Alt image pan, directory switching, physical ancestor refresh, details geometry, visible-only images and actual video playback/seek across bounded ranges. One later Markdown run failed to display; its next instrumented run passed, leaving that intermittent failure unresolved. Physical input, the unavailable reported network drive, high-DPI combinations and clean installation are not covered by these passes. This is not a final release acceptance.
