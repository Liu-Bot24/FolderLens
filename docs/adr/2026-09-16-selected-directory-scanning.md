# 只扫描当前选择的目录范围

用户实测从盘符切到子文件夹后，地址已经变化，扫描根仍为整个盘符，发现文件计数不断增加而当前结果仍为零。2026-09-16 用户明确选择：停止上一范围扫描，只扫描新文件夹及其子目录。本决策替代 2026-09-14/15 ADR 中跨导航保留扫描和复用祖先扫描的部分；索引身份、版本核验与目录完成后才能核销的规则保留。

目录导航持有根切换锁，取消并等待全部旧扫描退出，再解析和扫描实际选择的路径。停止旧扫描时保留已接受目录的监听器，若新目录准入失败，旧视图仍可响应文件变化。成功准入后退役旧监听器。旧进度在根身份和 epoch 检查之前不能写入当前进度缓存。

仅修改筛选或重新查询当前目录不等于切换文件夹，不无故重建扫描。旧保存视图和容量导航中以“父根加子范围”表达的位置，恢复为该子目录自身的根，并换算选择和滚动锚点。快速连续导航依赖已有导航版本阻止过期结果发布。

验证必须包含：父扫描尚未结束时进入子目录、连续切换只接受最后目标、返回父级、完成扫描后再进入子目录计数不继承、旧保存视图的位置及选择恢复、准入失败保留旧监听。隔离测试不代替真实大目录首屏性能验收。
