# 可清退的浏览数据与独立收藏映射

用户明确要求：重启后打开目录必须重新读取磁盘，普通扫描历史不长期保存；收藏类似播放列表，只保留收藏夹与文件位置的映射。缩略图允许跨启动保留，但七天未访问应清退，不能无限增长。

## 存储边界

- `collections/playlists.sqlite` 只保存收藏夹定义、文件路径、位置身份及加入时间。不复制原文件，不保存扫描结果或媒体元数据。
- `runtime/<instance>/` 保存本次运行的目录索引、结果快照、工作进程临时文件、目录树临时表和 WebView 数据。正常关闭后清理；异常退出后下次启动先回收。复用现有带所有权标记、锁及防重解析点检查的清理器。清理失败明确报错，不无限创建副本。
- `cache/thumbnails/` 保留编码后的缩略图，默认总磁盘预算 256 MiB、最多 4096 条、最后访问后七天到期。启动、访问过期条目及使用过程中的每小时维护会清理；预算不足时按最近访问时间淘汰未占用的条目。
- 配置只保存小型用户偏好。扫描数据库不再升级、备份或跨启动复用。

收藏库通过 SQLite 附加数据库与当前运行的工作表衔接，收藏变更在持久收藏库内原子提交。工作数据库即使在崩溃时未同步落盘，也会在下次启动重建。打开收藏只核验已收藏路径，不为恢复收藏递归扫描来源目录。正常目录扫描根据匹配的位置身份恢复星标和标签过滤。确认改名、替换或删除后移除映射；无法访问和不同卷不作为删除证据。

首次转换只读旧库中的收藏表及其引用的路径身份，不复制旧索引。完成标记避免用户删除收藏后再次从旧库导入。旧库回收属于单独维护操作，须保留收藏映射并核对授权清单。

持久缩略图的键还包括当前扫描的文件身份和变化签名，防止工作索引重建后版本号重复，使同路径替换文件错误命中旧图。

## 相关修复与验证

自动目录核对处于 partial 时，已经确认的移除也会发布到列表，仍显示未完成状态。目录容量的实时查询在同一读事务中取得当前 root epoch；旧窗口跟随新扫描，而冻结结果容量继续保留原快照。

回归覆盖重启后普通历史为空且收藏仍在、只恢复收藏路径、标签排除、原库只读迁移、删除收藏不被重复导入、同名替换不继承收藏、容量跨 epoch 与固定快照、七天按访问时间清退及数量/字节预算。原生 UI 与本机大规模扫描性能验证未运行，不能据此宣称正式安装验收通过。

## 收藏恢复复审修正

收藏库版本 2 独立保存文件身份与键生成时的大小写规则。规则未知或键变化本身不证明文件替换；身份确定不同才按替换移除。版本 1 小库原位增加两列，不复制旧扫描库；旧记录只有摘要时，必须匹配同一文件身份生成的摘要才补齐证据，不能因不匹配猜测删除或绑定新文件。

收藏页 F5 复用打开收藏的完整路径核验和请求代次控制。打开或恢复收藏视图后自动启动已有预算内的元数据补充，候选取自全部收藏成员，不依赖尺寸或时长筛选已经命中。恢复视图期间暂缓的结果发布在恢复结束后接续。原生验证入口改为实际调用 F5 和恢复筛选，不手动预先补元数据；本轮未运行该窗口入口。
