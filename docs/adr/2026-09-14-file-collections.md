# 本地文件收藏夹与跨目录浏览

用户需要自行命名的收藏夹，用于图片、视频、文档等所有文件类型；一个文件可属于多个收藏夹。收藏归属同时用于普通目录筛选中的包含与排除。现有保存筛选视图保留，两者不是同一种数据。

收藏夹与归属持久化到本地 catalog SQLite。集合 ID 稳定，名称可修改；文件归属以规范化位置键去重，引用已索引文件，不复制或修改原文件。Windows 非区分大小写目录使用 Unicode 大写位置键，区分大小写目录保留原拼写。同一物理路径从父目录和子目录分别建索引时，收藏筛选可匹配两份索引；收藏夹内按位置只显示一个代表项，优先当前存在的项。索引确认的重命名按旧位置键同步归属，包括其他索引根中同一路径的归属；无法追踪的外部移动不猜测重绑定。已有 missing 记录保持可见。

catalog / sessions 升到 v4，升级前备份数据库。新增位置索引及收藏表；会话保存每项源 root ID、路径与 epoch。旧单目录会话的新字段允许为空，仍按原目录解析；不因添加字段使有效旧会话失效。SQLite 函数和触发器维护位置键，避免每次筛选全表计算绝对路径。

收藏浏览使用独立 collection 范围，复用现有有界快照、分页虚拟化、类别筛选和预览。源路径从每项来源解析；UI 查询代次与源文件元数据的 root epoch 分开校验。收藏入口不会扫描任意源目录。跨目录同名文件的浏览位置用完整源路径区分。物理目录分组仅适用于普通目录视图。

包含多个收藏夹表示命中任一个；排除多个收藏夹表示排除任一个。两者同时设置时先满足包含，再满足排除，所以重合项被排除。普通目录的根范围、类别与其他筛选仍取交集。收藏条件保存在现有视图/会话 FilterSpec 中。

批量收藏从受保留的稳定会话读取选择区间，数据库内处理，不常驻所有行。单次操作 30 秒期限，取消或失败回滚整个归属事务。每次可选择最多 64 个收藏夹，最多 512 个命名收藏夹；界面不显示被截断的假完整列表。删除收藏夹仅删除其归属。

验收须涵盖多根来源、同名文件、图片/文本预览、PPT 分类、普通目录与收藏夹中的标签排除、重启持久化、重复添加、批量原子性、旧库迁移、已知失效引用。当前开发记录与运行结果以本地验证日志为准；本设计文档不声明发布 GO。
