# 本地文件收藏夹与跨目录浏览

用户需要自行命名的收藏夹，用于图片、视频、文档等所有文件类型；一个文件可属于多个收藏夹。收藏归属同时用于普通目录筛选中的包含与排除。现有保存筛选视图保留，两者不是同一种数据。

收藏夹与归属持久化到本地 catalog SQLite。集合 ID 稳定，名称可修改；文件归属引用已索引文件，不复制或修改原文件。位置键组合父目录物理身份、按该目录大小写规则规范化的文件名、文件物理身份；不能把叶目录的规则用于折叠整条路径。身份未确定时使用保守的索引项键。同一物理目录项从父目录和子目录分别建索引时匹配同一归属；不同硬链接名称保持不同归属。

用户于 2026-09-14 明确修订：文件改名、移动或确认删除后移除原收藏归属，不跟随文件迁移。交换文件名也不能继承或合并收藏。目录不可访问、设备离线与未扫描到不构成确认删除。仅身份观察补全可以更新键而保留归属，不能据此跟随已知路径改变。

catalog 升到 v5，sessions 保持 v4，升级前备份数据库。v5 原子重建位置键并按既有 anchor entry 转换归属；中途失败回滚，不宣称可以推断并恢复旧版已经合并丢失的归属。会话保存每项源 root ID、路径与 epoch；旧单目录会话字段允许为空，仍按原目录解析。SQLite 函数和受根/目录索引约束的触发器维护位置键，避免每次筛选全表计算绝对路径。

收藏浏览使用独立 collection 范围，复用现有有界快照、分页虚拟化、类别筛选和预览。源路径从每项来源解析；UI 查询代次与源文件元数据的 root epoch 分开校验。收藏入口不会扫描任意源目录。跨目录同名文件的浏览位置用完整源路径区分。物理目录分组仅适用于普通目录视图。

包含多个收藏夹表示命中任一个；排除多个收藏夹表示排除任一个。两者同时设置时先满足包含，再满足排除，所以重合项被排除。普通目录的根范围、类别与其他筛选仍取交集。收藏条件保存在现有视图/会话 FilterSpec 中。

批量收藏从受保留的稳定会话读取规范化选择区间，通过 session/ordinal 索引读取所选范围；同一操作只整理一次所选位置供多个收藏夹复用，不常驻所有行。单次操作 30 秒期限，取消或失败回滚整个归属事务。每次可选择最多 64 个收藏夹，最多 512 个命名收藏夹。删除收藏夹仅删除其归属，并移除失效筛选条件、刷新当前结果。收藏范围不提供物理目录容量入口。

验收须涵盖多根来源、同名文件、图片/文本预览、PPT 分类、普通目录与收藏夹中的标签排除、重启持久化、重复添加、批量原子性、旧库迁移、已知失效引用。当前开发记录与运行结果以本地验证日志为准；本设计文档不声明发布 GO。
