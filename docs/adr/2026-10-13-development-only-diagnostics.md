# 诊断日志仅用于开发版

## 决策

开发版可用本机诊断排查扫描和预览错误；正式版不收集、写入或打包应用诊断日志。该要求替代“所有版本默认匿名日志”的旧约定。开发记录可以包含本机路径和异常详情，不能描述为匿名；两种版本都不新增自动上传。

`FolderLensBuildFlavor` 在编译时确定策略。`Production` 关闭日志，设置或命令行不能重新开启。Release 优化的开发版使用显式 `Development` 属性。构建元信息与程序集元数据记录版本类型，避免把编译优化配置误认作产品发布类型。

扫描状态和界面错误处理独立于日志；禁用日志不能掩盖失败或假报完成。扫描日志、异常轮转文件、查询失败记录和 WebView 事件统一服从此策略。打包按清单检查并拒绝日志和用户数据。显式运行的隔离验收报告、构建输出在包外保存，不作为产品运行日志附带。

## 验证契约

分别构建 Development 与 Production，验证启动、图片呈现、查询失败保留原结果及错误提示。开发版必须生成有界记录，正式版必须没有对应文件，含传入 `--diagnostic-ui` 的情况。异常记录与日志洪水单测也按两种编译策略运行。包检查须同时拒绝诊断文件并允许正常运行组件。
