# 按需加载、可调布局和基本文件管理

日期：2026-09-15。状态：用户已授权实施；验证结果见同批测试记录，不代表全部一期验收完成。

## 依据与边界

FastStone 本机实际交互验证支持可快速浏览的列表、可独立调整的预览区域、显式视频播放、缓存管理与现有幻灯片操作。无法证明其完整缓存淘汰算法，因此保留 FolderLens 256 MiB 上限及七天未用清理，不复制其大体积数据库。

用户最新授权覆盖旧的“源文件完全不可修改”范围：允许用户显式重命名、移动、删除单个文件；收藏仍是位置映射，改名、移动或删除后不跟随。禁止双图比较、目录书签、评分、自定义快捷键、格式转换和源 EXIF 回写。

## 统一需求与成本原则

- 枚举继续穿透子目录，当前浏览目录优先；切到其他应用仍继续，不用窗口失焦作为扫描暂停条件。
- 普通名称、文件大小、文件日期、层级、扩展名浏览不启动整根内容探测。RAW 开关在内容身份未知时按扩展名候选分类；已读取的明确内容身份优先。它与文件类型候选一样服务即时浏览，不是内容真实性鉴定。这个变更需要独立查询 oracle 同步新契约。
- 尺寸、动图、内容格式、时长/编码/帧率等过滤或排序产生内容需求。只探测满足当前目录、层级、名称、类型及已知条件的候选；过滤所需而尚未知的信息继续读取，不能伪造匹配。
- 普通内容探测不顺带读取 EXIF/色彩详细信息。拍摄日期过滤/排序、用户明确重新读取信息、当前预览和属性窗口才请求详情。
- 可见详情行/缓存命中但缺少基础信息的行按需补读。滚走或切根后取消。可见视频封面需要的 probe 结果直接存入当前临时目录，避免再探测一次。
- 相邻预览沿用有界数量及内存限制，尺寸与当前显示表面一致；不再为未被放大的图片提前读取中心高清图块。实际缩放仍走原有区域解码。
- 目录容量窗口仍按用户打开/刷新时计算，扫描仅记录必要文件属性，不触发全媒体解码。动画和视频播放仍由用户显式触发，文本分页保持有界。

## 文件操作和布局

新增上下分隔条，保存比例，双击恢复默认；窗口预览/全屏进入退出恢复侧栏。旧 desktop.json 缺少比例时默认 60% 目录、40% 预览。

文件菜单、右键菜单与 F2/Delete 共用单文件操作流程；编辑框和菜单拥有输入时不抢快捷键。执行前核对当前选择、根代次、源路径与版本；操作期间退出当前预览。重命名和移动采用 .NET File.Move（不覆盖目标），回收采用 .NET Microsoft.VisualBasic.FileIO 的 Windows Shell 删除流程，保留 Windows 取消与错误提示。成功后才退休旧目录记录并清除原位置收藏，再重新扫描展示；失败不得标成功。暂不提供批量文件管理和覆盖同名文件。

原有幻灯片增加 1–60 秒间隔和循环设置，显示播放/暂停动作，保持从当前图片开始、跳过非图片、Esc 返回并结束；未引入转场与音轨等扩展功能。

## 验证与限制

新增真实扫描 100 个 PCM 文件、按名称和时长条件只读取其中 1 个的测试；基础 RAW probe 不返回 EXIF、显式详情请求返回 EXIF；重命名与移动的源内容保持、目标冲突拒绝、源版本改变拒绝、旧收藏失效；RAW 未探测候选与幻灯片循环正反例。

Windows 回收站确认对话框和分隔条实际手势需要原生界面验证；单元测试与编译不能替代它们。没有本轮与 FastStone 的同目录冷盘吞吐比较，不声称已经达到相同性能。
