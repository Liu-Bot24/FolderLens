# 浏览层级与文件名搜索

当前目录算第 1 层，`FilterSpec.MaxFolderLevels` 为可空正整数（1–32767），空值表示所有层级。相对于 `DirectoryScope` 计数；选择 3 层时显示当前目录及下面两级目录直接存放的文件。图片、视频和普通文件共用同一条件。

这是浏览条件，不是扫描限制。界面默认递归扫描，层级切换只更新查询，不取消或重新启动扫描，不修改索引结构。旧 `recursive=false` 保存视图在界面恢复为 1 层浏览；底层兼容旧扫描调用。新字段参与保存、历史及固定结果会话，首屏和完整结果共用 SQL 条件。物理目录容量的“仅直属文件”范围仍更严格；显式选择层级会清掉该快捷限制。虚拟收藏夹跨多个物理位置，层级入口禁用，查询忽略层级字段。

文件夹分组的匹配数受浏览层级限制；“整个已扫描目录”容量仍按原定义统计整个子树，不假称磁盘内容被移除。所有后台扫描与元数据补充保持原有资源约束。

用户确认浏览搜索仅匹配文件名称。移除路径搜索选项；旧 JSON `searchScope=nameAndPath` 继续可读取，但查询统一搜索文件名，界面重新保存为 `name`。

格式下拉使用 WinUI 左边缘对齐；窗口预览和全屏预览集中在左侧预览区。100% 文本按钮按内容测量并留出边距。物理交互验证与编译验证分别记录。
