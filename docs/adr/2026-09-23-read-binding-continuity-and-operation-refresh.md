# 读取绑定连续性、水合授权与文件操作核对

## 背景

对 `976d73a` 的复审指出：未知身份可能被当成强绑定；旧绑定因请求代次失效后，内容元数据可能错误复用；父目录的水合后检查不足以保护下载副作用；停止扫描后的文件操作缺少完成核对；占位文件的卷查询不应复用内容读取排除策略。

## 决策

- 补全结果必须包含非空文件身份。工作进程与绑定写入端均检查；未知身份不得提交可复用绑定，不放宽下游签名比较。
- 请求归属和内容连续性分别核对。跨根代次、目录位置修订的旧绑定仍作为内容证据；同一内容版本观察到不同完整签名时，同一写事务递增文件版本、清除内容派生列、FileDetails 和 FieldStates，再写入新版本绑定。持有旧版本的请求返回文件变化，必须重新解析，迟到的旧元数据写入被版本条件拒绝。相同完整观察保留元数据。
- 水合请求带已批准的父目录身份和解析位置。工作进程从根至父目录持有读取目录的句柄，拒绝写入和删除共享，拒绝不支持的重解析组件，核验最终父目录后才打开并水合文件；全程保留原文件与事后父目录校验。
- 目录锁定使用 `FILE_LIST_DIRECTORY | FILE_READ_ATTRIBUTES`。仅属性访问句柄不参与所需的共享保护，真实改名反例已证明不能用于此锁定。目录链无法可靠锁定时应拒绝水合，不能退回存在替换窗口的路径检查。这只影响显式云水合，不增加普通图片读取的目录锁。
- ScanWorker 消息 `Version` 仍为 1，配套 `Build` 升级为 `folderlens-scan-0.1.0-v7`，新增父目录授权及属性级 `volume` 请求。卷查询不打开数据流、不水合，普通 `stat` 的批准策略不变。未知卷默认复制，Ctrl/Shift 语义不变。
- Shell 完成核对由独立浏览视图令牌控制，导航取消但停止扫描不取消。扫描已停止时，核对捕获操作涉及的、已登记的父目录以及当前浏览目录，限时 30 秒、严格单层；不修改根扫描状态，不恢复原扫描任务，不进入新发现的无关子目录。原有递归扫描和普通脏目录核对策略保持原样。

## 验证与限制

见 [复审修复验证](../VALIDATION_PRO_976D73A.md)。真实云提供程序的完整水合、权限及共享兼容矩阵仍待验。目录读取权限不足、存在不支持的重解析链或共享冲突时，安全拒绝不等于成功恢复读取。属性级卷查询的占位行为使用真实 deferred 属性文件验证，不冒充真实云提供方下载测试。
