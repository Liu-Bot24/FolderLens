# Reuse scan context when browsing its subdirectories

Opening a scanned child through the tree previously called `OpenRoot(child)` and stored the same subtree under another root ID. The capacity view already supported changing `DirectoryScope` inside the existing root. Ordinary refresh also passed the metadata invalidation flag to the scanner, making unchanged media require decoding again.

Directory navigation now reuses a known exact-case scope in the current root, or a covering active background scan with matching scan policy. The address field, parent navigation, history, file selection, and query depth follow the browsed directory. New or incompatible scopes still resolve an independent root normally. This does not globally merge physical identities, hard links, or differently cased paths.

Scope navigation queues a subtree reconciliation and raises its existing scan priority. A running parent enumeration finishes before reconciliation starts, preserving its epoch and single-enumerator ownership. The reconciliation updates existing rows and confirms deletions only after successful enumeration. This is current-session reuse, not persistent browsing history. Watcher events remain revision-protected. Ordinary refresh re-enumerates but invalidates metadata only when the source signature/state changes; explicit infrastructure-level forced invalidation remains available.

The Pro investigation independently confirmed the RAW forced-development path. Camera preview completion was fixed separately. A further confirmed issue was treating every LibRaw thumbnail as an encoded file. `RawPreviewImage` now distinguishes encoded JPEG/JPEG-XL from bounded 8/16-bit bitmap data, preserves bitmap orientation and rejects truncated output. The diagnostic command exercises the actual libvips image path without creating configuration/cache files.

Validation: generated child-directory reconciliation adds new files, retires deleted files, preserves unchanged geometry/version, does not create another root, and still invalidates changed files. Exact-case scope tests include drive roots, sibling-prefix and other-drive counterexamples. Native tree/parent navigation and F5 assertions are compiled but not run. Worker checks cover bitmap bytes, rotation, JPEG, malformed bitmap and a public Sony ARW. Final suite: 418 passed, zero skipped. Native rendering and the reported RAF sample remain unverified.

The Pro report also identifies full snapshot rewriting and scan-history storage as potential costs. Current result-history limits already exist; no evidence supports unlimited retained history. The original entry's runtime directory was empty after exit, so the previous large database was unavailable for page statistics. No storage-share percentages are asserted, no private database is copied, and indexes/snapshot consistency are not changed without measurements.
