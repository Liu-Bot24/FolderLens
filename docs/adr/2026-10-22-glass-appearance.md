# 琉璃外观

## 背景

现有“原生”“柔和”两套外观以替换资源字典的方式运行时切换。需要新增一套更有质感的可选外观，同时不改变布局结构、预览与全屏交互、浏览状态及原有两套外观的显示。

## 决策

- 新增第三个资源字典 `Themes/Glass.xaml`，持久化值为 `glass`；默认外观仍为“原生”，无法识别的值仍回落到“原生”。
- 面板背景使用窗内亚克力（`AcrylicBrush`），叠加在主窗口最底层的静态极光装饰层之上。装饰层不可点击，其他外观下透明度为 0。未采用窗口级 Mica/Acrylic 背景：窗内亚克力无法可靠地采样系统背景，且效果会随桌面壁纸变化。
- 预览与全屏图片背后的底色保持中性灰（`#18191C`），符合“预览背景独立深中性灰”的要求，避免对照片着色。
- 原先模板中写死的视觉值（预览底色、视频播放按钮、缩略图与角标圆角、全屏浮层样式）改为主题资源；原生与柔和填入原值，外观不变。
- 全屏四边浮层在琉璃下离边缘 14 px、圆角并始终使用深色主题，淡入并从所在边缘轻微滑入。仍为贴边悬停唤出，不增加常驻标题栏。悬停保持判断把浮层边距计入范围；原生/柔和边距为 0，判定结果与原来一致。
- 琉璃右侧信息面板仅调整排版（标题加粗、标签弱化），文本内容与原来相同。高对比度下使用系统颜色、无透明与装饰。

## 验证边界

原生离屏测试覆盖三套外观的对比度、运行时切换往返、浏览状态保持、浮层主题与边距、悬停范围正反例和全屏边缘底色。`RenderTargetBitmap` 截图无法呈现亚克力模糊；真实观感、动画手感和 GPU 开销需在前台实机确认。
