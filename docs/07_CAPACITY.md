# 07｜目录容量与排名

## 1. 两个范围、两个口径

范围一“整个已扫描目录”：所有已枚举普通文件，不受图片/视频/隐藏视图等筛选影响，明确排除SkipScan、权限失败和未完成区域。
范围二“当前筛选结果”：绑定固定resultSessionId，仅确定Match项。待判断/无法判断数量单独显示，不掺入已匹配字节。

逻辑大小=文件流长度累计。分配大小=API可提供的已分配存储值；失败/不支持为NULL；GetCompressedFileSizeW可反映压缩/稀疏文件占用，但不能简化成删除可释放空间。[S09]

默认单位自动IEC（KiB/MiB/GiB），悬停给精确字节。用户切SI需全页一致，不用“GB”标1024进制。百分比以同一范围/同一口径/同一revision的父总量为分母。

## 2. UI与层级

当前层：每个直接子目录的子树累计 + “本目录直接文件”项；按大小降序、路径作为稳定次序；占比条最多前20项，余下合并“其他”，合并不影响完整排名表。

可切“所有后代目录排名”：显示相对完整路径、层级、子树累计。**此表中父子目录相互重叠，禁止对全部排名项再求和或绘制互不重叠饼图。**

下钻目录后重新显示其直接子目录和直属文件；返回上一层保留排序和选中。点击空间项可转到文件浏览并设置对应路径范围（仍是同一根），不能偷偷变更为另一个扫描根。

## 3. 统计架构

扫描器提供每文件逻辑大小和父目录；基础直接文件大小在同一写事务用旧→新差值更新，不能按watcher事件盲目累加。目录结构维护parentId/depth；子树聚合后台按自底向上归并，批量写新aggregateRevision，完成后原子切换可见版本。

目录移动：旧父链减、新父链加，以实际目录项重验为准；批量变更/灾难恢复允许重算受影响子树。禁止每新文件递归扫描整个父子树。聚合可重建，catalog和用户配置不可被清缓存一并删除。

当前结果容量只扫描session表中的Match项，用快照保存的logicalBytes/allocatedBytes按目录归并；不重新跑一个时间点不同的过滤SQL。文件期间变化显示“基于结果生成时数据”；刷新结果后容量一起换版本。

分配大小按需低优先级补齐，初始浏览不必等它完成。用户切分配口径提升该任务优先级但仍低于当前原图。远程位置不支持时停止重复探测、记录provider能力；不给每个文件无限重试。

## 4. 硬链接与其他边界

默认“按路径累计”：同一底层文件多个目录项会重复计入，这与展平列表一致；页面显式标注。可提供“当前范围底层文件去重总量”作为辅助指标，但只有physicalIdentity覆盖完整时标精确，缺失时不给假精确值。

一期不把硬链接后的独占释放空间分摊给各目录，不做“删除此目录能释放X”建议。ReFS块共享、压缩/去重存储、远程服务端分配、备用数据流、目录元数据、回收站和文件系统保留空间会导致文件加总与整盘使用量不同；产品口径是普通文件主数据流统计，界面说明而非强行补差。

符号链接/联接不递归重复计数；链接项本身不代表目标子树占用。云占位逻辑大小与本地占用分别显示，未知分配不能写成0。可选显示volume free space，但与目录加总隔离，不当作对账等式。

0字节文件、空目录保留；父总量0时占比显示—而不是除0。数值用checked 64位累计，超过范围时明确错误而非负数。

## 5. 完整性合同

每份结果返回scopeId、revision、measure、knownBytes、knownFileCount、unknownFileCount、excludedDirectoryCount、errorDirectoryCount、scanState、calculatedAt。完整状态是complete/partial/scanning/offlineSnapshot，而不是一个总数。

扫描完成≠allocated已完整。存在unknown allocation时显示“已知分配大小X + Y项未知”，占比标“基于已知值”，不得标整个目录精确占用。网络离线时只保留上次快照和时间戳。

必须用固定人工可核算目录测算：根直属10、A直属20、A/AA30、B40，根100，A50；同层A50+B40+直属10=100；全层排名A50、B40、AA30不可再求和当根120。还有SkipScan/HideInView、硬链接、稀疏、未知分配和移动目录测试。
