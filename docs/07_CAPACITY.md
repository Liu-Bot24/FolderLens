# 07｜目录容量与排名

## 1. 统计范围与口径

用户打开目录容量时，应用独立枚举当前文件夹及其子目录的文件元数据，不依赖主浏览索引是否扫描完毕，不受图片、视频和名称等视图筛选影响。SkipScan 范围不进入统计；权限失败、离线和尚未枚举的范围标为未完成。主列表的临时筛选结果不作为容量窗口的可选范围。

界面大小是普通文件主数据流的长度合计。文件系统分配大小仍可作为底层元数据供其他功能使用，但目录容量窗口不显示“占用空间”切换或第二张总量卡片；该数也不能直接代表删除后可释放的空间。大小使用 IEC 单位，悬停显示精确字节。

## 2. 分层排名与导航

按一级、二级、三级及更深层级分别排名。选定深度后，每条分支只列该深度的目录；如果分支不足选定深度，列它最深的目录。因此，同一榜单不会同时出现一条分支上的父目录与子目录。名称显示相对于当前查看目录的路径；按子树文件大小降序、完整相对路径稳定排序。

右侧分布显示排名前 20 个目录，余下合并为“其他子文件夹”。上层目录中的直属文件合并为“未列入排名的直属文件”，使分布总量与当前目录总量相符。排名表本身只列目录；各项占比的分母均为当前目录的总大小。没有子文件夹时，排名为空而总大小与文件数照常显示；总大小为零时，占比显示“—”。

双击目录可下钻，下钻后保持选定排名深度；返回上级保留之前的选中。选中目录后“在主窗口浏览”定位相应目录范围，遵守主窗口的导航与取消规则。

## 3. 统计与刷新

物理容量采用可取消的目录元数据遍历。每目录只保留一个直属文件聚合，再自底向上累计子树；不把每个文件写入浏览索引，也不触发媒体解码。遍历期间发布不完整下界；只有全部待访问目录结束且没有不可读范围才标记完整。切换排名层级只重排已有聚合，不重新扫描；点击刷新才重新枚举。切换主窗口浏览根或关闭容量窗口会取消旧容量任务。

已有结果快照聚合接口仅作内部兼容，不再通过容量窗口的“打开窗口时的筛选结果”选项调用。统计期间源文件变化可能使一次结果跨越多个时间点；需要重新核对时使用“刷新统计”。

## 4. 文件系统边界

默认按路径累计：同一底层文件的多个硬链接目录项会分别计入。符号链接、联接目录不递归重复统计；云占位、权限失败和网络离线不能作为零大小。ReFS 块共享、压缩/去重、远程服务端分配、备用数据流和目录元数据会使文件大小合计与磁盘已用空间不同。

0 字节文件和空目录保留。数值使用受检的 64 位整数累计，溢出明确失败。任何未完成结果均标记为下界；没有已统计文件不代表目录为空。

## 5. 可核算夹具

根直属文件 10、A 直属文件 20、A/AA 文件 30、B 文件 40：根总大小 100，A 子树 50。一级排名 A50、B40；二级排名 A/AA30、B40；三级超过实际深度，仍为 A/AA30、B40。上层直属文件余量为 30，右侧分布合计 100，且不出现 A 与 A/AA 同时排名。还应覆盖 SkipScan、部分统计、硬链接、空目录和刷新后源文件变化。
