# 00｜范围、默认决策与一期完成定义

## 1. 背景与目标设备

用户主要设备为 Windows 11、i9-14900KF、RTX 4090 24 GB、64 GB RAM；图片包含 Sony A7R IV A 的高像素 ARW。原始内容可能位于本地 SSD/HDD、移动磁盘或 SMB/NAS。不能根据高配配置假定所有数据都在 NVMe，也不能按 CPU 线程数无条件同时解码同样数量的文件。

应用定位为具有文件夹穿透能力的文件浏览器，汇总多种文件类型，图片和视频浏览为重点增强方向。源目录继续是事实来源；索引可重建，用户预设不可随清缓存丢失。2026-09-13 的一期调整见 [文件浏览器一期调整](FILE_BROWSER_PHASE_ONE.md)。

2026-09-15 用户确认：加入显式单文件重命名、移动和删除（优先回收站）；仍不做编辑、转换、双图比较、目录书签、评分、自定义快捷键。浏览、元数据读取和预览仍不改写源文件。加载原则统一为当前用户需求优先，详见 [按需加载与基础文件操作](adr/2026-09-15-demand-driven-browsing.md)。

## 2. 一期冻结范围

| 模块 | 一期必须达到的状态 |
|---|---|
| 目录 | 选一个根目录递归展平；本地/UNC；增量显示；刷新；排除；恢复上次会话 |
| 文件列表 | 缩略图网格、详情列表、虚拟化、相对路径、选择、多选、分页、可见项优先 |
| 筛选 | 类型/格式/RAW/动静态/尺寸/像素/比例/体积/分配大小/日期/时长/名称路径；条件保存 |
| 图片 | 清晰适屏、真正 100%、缩放平移、只读旋转、全屏、连续切换、幻灯片、透明和 EXIF 方向 |
| RAW | Sony ARW 为强制样本；内嵌预览和真实 RAW 解码分开；其他相机格式按矩阵 |
| 动图与多页 | GIF/APNG/Animated WebP 播放；多页 TIFF 页导航；动画帧与文件导航分开 |
| 视频 | 元数据、封面、筛选排序、系统播放器及指定 EXE、PotPlayer 适配和结果集播放列表 |
| 音频 | 元数据、封面、系统支持格式内置单项试听、进度/音量/倍速；失败外部打开 |
| 文本/MD | 普通文本预览、超大文本/MD 原文分页阅读和搜索；安全 Markdown 富文本预览 |
| 容量 | 同层目录占比、全层排名、下钻；全范围/结果范围；逻辑大小与分配大小区分 |
| 产品闭环 | 最近根目录、保存视图、状态恢复、定位原文件、复制路径、设置、错误说明、诊断 |
| 交付 | 原生应用、完整源码、锁定依赖、安装/便携包、测试与性能证据、用户文档 |

大文本分页阅读属于一期 MUST，不再把“超阈值只能外部打开”当成完成。超大 Markdown 以原文模式完整可读；不承诺任意体积的完整富文本排版。视频内嵌播放明确不做。

## 3. 一期明确不做

转换、压缩、导出图片、批量改名、写入式旋转、裁剪、RAW 参数编辑、EXIF 写回、去重及重复删除、AI/OCR/人脸索引、跨设备同步、账号云服务、网络视频/流媒体播放器、压缩包内部递归、PDF/Office 排版查看、PSD 分层编辑、完整 HDR 输出、插件市场、跨平台、ARM64/x86。

一期可展示其他文件的名称/体积/属性并显式交给系统打开；不执行未知脚本或可执行文件。用户单击未知文件仅显示属性。复制文件到系统剪贴板采用文件引用（CF_HDROP），不实现自有文件复制器，也不承诺超大量剪贴板操作。

## 4. 已冻结的实现选择

- UI：C#、.NET 10、WinUI 3；MVVM 使用 CommunityToolkit.Mvvm；不使用 Web 做主界面。
- 图形：Win2D/Direct2D。常见图片 NetVips；Magick.NET 仅作兼容/帧处理通路；RAW 为 LibRaw 薄适配。
- 数据：Microsoft.Data.Sqlite + 显式参数化 SQL，避免为百万列表引入对象跟踪 ORM。
- 音频：Windows.Media.Playback.MediaPlayer，只有一个活动实例；外部播放兜底。
- 视频：FFprobe/FFmpeg 探测与封面；无 libmpv、无 PotPlayer 内嵌/控制插件。
- 文本：有界分块 Reader + WinUI 只读窗口文本显示；不把整个文件绑定到文本框。
- Markdown：Markdig + 单个按需 WebView2；安全策略和阈值必须启用。
- 安装：Unpackaged、自包含、目录式发布；每用户安装 EXE + 便携 ZIP。不能把单文件 EXE 当硬目标。
- 首版中文界面、跟随系统明暗、单主窗口、单活动根目录。最近根目录可多个，但不混合多根目录查询。
- 默认无自动联网、无遥测、无内容上传、无后台登录后自启、无关闭窗口后继续扫描。

以上选型为本项目决定；依赖能力依据见 docs/13_SOURCE_REGISTER.md。所有“已冻结”指实现方向，不代表这些组件已在本项目一起编译运行。

## 5. 技术基线与版本冻结

截至 2026-09-12 核查，微软下载页提供 .NET SDK 10.0.401，Windows App SDK 稳定版本为 2.4.0；2.4.1-experimental 不采用。[S01][S02]

M0 以此作为起始候选，完成实际 restore/build/publish/launch 后，把通过组合写入 global.json、Directory.Packages.props、packages.lock.json、dependency-lock.json。其余 NuGet/原生组件选择核验时稳定版并精确锁定；不在本文编造未验证的全部包版本。

TargetFramework 起点为 net10.0-windows10.0.26100.0，TargetPlatformMinVersion 为 10.0.22000.0，RuntimeIdentifier 为 win-x64。仅对微软仍支持的 Windows 11 版本给出产品支持承诺。API 必须做运行时可用性检查；SDK/模板不接受某配置时在 M0 记录真实错误并选择可编译的等价 Windows 11 配置，不得静默迁移技术栈。

## 6. 完成定义与权限边界

一期完成要求：所有 MUST 有实现、有可复现证据且强制测试 PASS；源文件不被修改；无 RELEASE-BLOCKER；标准与低资源环境可控；便携包和安装包实际验证；文档、依赖与实际格式能力一致。

编译通过不等于 UI 正确；UI 能启动不等于性能通过；具有文件扩展名不等于已支持该格式。缺少环境或真实样本可以造成验收阻塞，但不能自行删除该项需求。

对未明确的问题采用本包默认值。对付费、凭据、系统级安装、外部发布遵守环境实际权限。最终用户机器未授权运行时，只完成开发/构建机工作，明确未安装到用户机器。
